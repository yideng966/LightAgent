# 微信群图片回复思考泄漏修复开发方案

## 1. 任务状态

- 状态：已完成
- 日期：2026-07-31
- 目标：修复微信群图片理解后，主文本模型把“用户可能想让我……我可能会这样回应……”等无标签内部答复规划作为普通正文发送到群里的问题。

## 2. 已确认现状

微信群图片回复当前分为两次模型调用：

1. `WechatGroupMultimodalContextService` 调用视觉模型生成图片摘要。
2. Agent 主文本模型读取图片摘要、群聊上下文和人设，生成最终群回复。

当前存在两项风险：

- 已部署用户的持久化 `config.json` 会继续保存旧视觉提示词“请简洁描述……并指出可能需要回复的内容”，仅修改模板不会覆盖旧值。
- 全局 `enable_thinking=true` 时，携带图片摘要的主文本模型请求仍会开启思考；部分自定义兼容端点会把内部规划混入普通 `content`，现有确定性标签清洗无法识别无标签自然语言思考。

## 3. 设计原则

- 不自动覆写用户持久化 `config.json`。
- 不使用自然语言关键词或正则猜测、截取无标签思考。
- 用户配置继续表达“希望视觉模型关注什么”，不可配置的输出边界由代码强制追加。
- 只对微信群图片上下文请求关闭思考，不影响普通群聊、Web 思考展示和其他渠道。
- 复用现有 `LLMRequest.request_options` 与 `reasoning_effort=none`，不新增配置项或 Provider 私有旁路。

## 4. 实施方案

### 4.1 运行时视觉提示词解析

在 `wechat_group_multimodal_context_service.py` 中集中定义：

- 旧版默认提示词；
- 新版客观描述默认提示词；
- 代码所有的强制输出约束。

解析规则：

1. 配置为空时使用新版默认提示词。
2. 配置与旧版默认提示词完全一致时，在运行时替换为新版默认提示词。
3. 其他自定义提示词原样保留。
4. 所有基础提示词最后追加强制约束：只陈述图片中可观察事实和文字、限制长度、不推测发送者意图、不拟写回复、不描述分析过程。

解析只影响实际视觉请求，不修改内存配置和磁盘配置。图片摘要缓存键包含最终提示词，升级后会自然避开旧提示词缓存。

### 4.2 图片上下文请求级关闭思考

在 `AgentStreamExecutor` 创建不可变 `LLMRequestSourceSnapshot` 时，根据当前请求上下文生成请求选项：

- 非微信群请求：保持现状。
- 微信群原始图片消息（`trigger_source=image_message`）：设置 `reasoning_effort=none`。
- 微信群文本消息匹配到图片上下文（存在 `wechat_group_multimodal_matched_images`）：设置 `reasoning_effort=none`。
- 普通微信群文本请求：继续跟随全局 `enable_thinking`。

`AgentLLMModel._build_call_kwargs()` 已能把 `reasoning_effort=none` 转换为 `thinking={"type":"disabled"}`，并对主备候选从同一不可变请求源重建，无需修改 Provider 路由。

### 4.3 默认配置与规则同步

- `config.py` 与 `config-template.json` 改用新版客观默认提示词，服务于新安装用户。
- `AGENTS.md` 明确微信群图片上下文请求是全局思考开关的受控例外。
- 不自动迁移或回写已部署配置。

## 6. 测试方案

### 6.1 视觉提示词

- 空配置使用新版默认提示词并追加约束。
- 旧默认配置在运行时替换为新版默认提示词，不再包含“指出可能需要回复的内容”。
- 自定义配置被保留并追加约束。
- 强制约束不会重复追加。
- 实际 `Vision.execute()` 收到解析后的最终问题。
- 同一图片在最终问题不变时继续命中缓存。

### 6.2 请求级思考控制

- 原始图片消息生成 `request_options={"reasoning_effort":"none"}`。
- 匹配近期或引用图片的文本请求同样关闭思考。
- 普通微信群文本请求不生成该覆盖项。
- Web 请求不受微信群图片标记影响。
- `AgentLLMModel` 对该请求实际生成 `thinking={"type":"disabled"}`，全局 `enable_thinking=true` 也不能覆盖。

## 7. 验收标准

1. 升级后的已部署实例无需修改持久化配置，旧默认提示词在实际视觉请求中自动失效。
2. 用户自定义视觉关注点得到保留，但不能移除代码所有的客观输出约束。
3. 所有微信群图片上下文 Agent 候选均收到请求级禁思考控制。
4. 普通微信群文本、Web 和其他渠道的思考行为无回归。
5. 定向测试、关联测试、语法检查和 `git diff --check` 通过。
