# 发布 LightAgent v2.2.2 计划

## 状态

已完成

## 目标

将 `v2.2.1-dev` 之后已经提交并验证的两项交互修复发布为补丁版本 `v2.2.2`，创建发行元数据提交和附注标签，并推送 `master` 与标签到 `origin`。

## 发布范围

- 修复 Android 浏览器动态视口变化后 Web 控制台顶部导航和侧边栏入口不可见的问题。
- 修复微信群管理员门禁详情展开或收起时页面跳顶，以及普通成员触发门禁能力时权限提示误发到群内的问题。

## 执行步骤

- [x] 核对本地与远端最新标签，确认下一个稳定版本为 `v2.2.2`。
- [x] 新增并校验 `docs/releases/v2.2.2.md`。
- [x] 将 `cli/VERSION` 与 `pyproject.toml` 同步为 `2.2.2`。
- [x] 更新 `CHANGES.md` 并运行发行契约、相关回归和全量 Python 测试。
- [x] 创建简体中文发行提交和附注标签 `v2.2.2`。
- [x] 推送 `master` 与 `v2.2.2` 到 `origin`，核对远端引用。

## 验收标准

- `docs/releases/v2.2.2.md` 通过仓库发行说明校验。
- 两个版本来源均为 `2.2.2`。
- 自动化回归、JavaScript 语法与差异检查通过。
- `master` 和附注标签 `v2.2.2` 成功推送到 `origin`。
- 标签指向包含发行说明、版本文件、变更记录与本计划的发行提交。

## 回退边界

- 打标签前发现问题时只修正本地发行提交，不创建或移动远端标签。
- 推送分支成功但标签失败时，仅重试推送同一已验证标签，不重建同名标签。
- 不纳入工作区中未跟踪的回复链路分析文档，不连接或操作远端部署环境。
- 按仓库规则以 Git 引用推送成功为完成条件，不等待 GitHub Actions 或镜像构建终态。
