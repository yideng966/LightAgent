# 进退群消息开关默认开启开发计划

## 目标

让 Web 控制台现有的“入群欢迎”和“离群通知”两个独立开关继续保存到 `config.json`，并将新配置及旧配置缺少对应字段时的默认状态统一调整为开启。

## 范围

- 调整 `config.py` 与 `config-template.json` 中两个开关的默认值。
- 调整进退群配置归一化和 Web UI 缺省展示，确保缺键时前后端均按开启处理。
- 保留现有按稳定群“跟随全局 / 自定义 / 关闭”逻辑，不改变成员事件安全门禁和发送链路。
- 补充配置归一化、Web 保存落盘和示例配置回归测试。
- 同步更新用户说明、协作规则与 `CHANGES.md`。

## 风险与回退

- 行为变化仅影响没有显式关闭对应开关的新配置或旧配置；显式配置为 `false` 时必须继续关闭。
- 按群 `disabled` 覆盖必须继续优先于全局默认开启。
- 回退时可将两个默认值及缺键 fallback 恢复为 `false`，不会迁移或删除用户数据。

## 实际改动

- 复用 Web 控制台现有的入群、离群独立开关及保存 API，没有新增重复控件或改变按群覆盖结构。
- 将 `wechat_group_join_welcome_enabled` 与 `wechat_group_leave_notice_enabled` 的示例默认值改为 `true`。
- 将后端配置归一化和 Web UI 的缺键 fallback 改为开启，同时保留显式 `false`。
