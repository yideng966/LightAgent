# 删除情绪与主动性开发计划

## 关联问题

- GitHub Issue：#24
- 标题：删除情绪与主动性功能，包括后台逻辑和 UI 以及配置项

## 目标

完整移除微信群“情绪与主动性”能力，不再维护群情绪状态、不再用情绪或时段规则调节自由回复、不再模拟打字延迟，并删除对应 Web API、Web UI 和默认配置项。

## 边界

- 删除情绪状态存储、服务、上下文注入、消息观察、回复记录和自由回复决策调节。
- 删除“情绪与主动性”Web 导航、面板、状态读取/重置/保存 API 与前端状态。
- 删除 5 个 `wechat_group_emotion_*` 配置项、2 个自由回复时段规则配置项和 2 个打字延迟配置项。
- 保留微信群自由回复本身、自由回复本地评分、Scorer、worker、冷却和频率限制。
- 不清理用户数据目录中历史生成的数据库文件，避免发布升级时主动删除用户数据；新版本不再读取或写入该文件。

## 实施步骤

1. 删除情绪服务、SQLite 存储及其专属测试。
2. 从微信群消息处理、上下文构建、自由回复和发送路径移除所有调用。
3. 从 Web 路由、配置接口、页面导航、面板和交互代码移除该能力。
4. 从默认配置、配置模板、当前文档和协作规则中移除对应说明。
5. 调整受影响测试，并增加“当前运行面不再暴露情绪能力”的回归断言。
6. 更新 `CHANGES.md`，完成相关测试后回写本计划。
7. 以单独 Git 提交交付 Issue #24；全部发布引用推送成功后关联关闭问题。

## 实际改动与验证结果

### 实际改动

- 删除 `WechatGroupEmotionService`、`WechatGroupEmotionStore` 及专属测试，不再创建或访问 `wechat_group_emotion.db`。
- 从 `WechatGroupChannel` 和 `WechatGroupHumanizedContextBuilder` 删除消息观察、回复记录、决策调整、打字延迟及 prompt 注入。
- 从 Web 配置响应、保存白名单、路由、处理器和 `console.js` 删除完整功能面；复用的时间与指标格式化函数改为通用名称。
- 从 `config.py`、`config-template.json`、README 和 `AGENTS.md` 删除现行配置与能力说明，并明确自由回复保留、情绪主动性不再存在。
- 删除旧正向能力测试，增加 Web 运行面不再包含旧标识的负向回归。
