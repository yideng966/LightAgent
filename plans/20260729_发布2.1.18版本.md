# LightAgent 2.1.18 发布计划

> **状态：** 已完成

## 1. 发布目标

将 `v2.1.17..master` 与当前已验证的群友画像自主学习修复发布为稳定版本 `v2.1.18`。发布提交先包含版本文件和 `docs/releases/v2.1.18.md`，再创建并推送附注标签；标签用于触发 GitHub Release 与 Docker 多架构镜像工作流，不以远端构建终态阻塞本次交付。

## 2. 发布范围

本次发行说明按用户价值归并为两组：

1. 群永久记忆的摘要、正文和 Dream 审计摘要统一使用简体中文。
2. 修复群友画像自主学习页面展开错位、异步状态丢失、重复刷新和画像数据不同步。

不包含内部文件清单、提交哈希、测试数量、开发过程、未确认路线图、凭据或部署标识。没有配置格式、数据库结构或行为默认值的破坏性变化。
