# 微信群焦点栈替代话题追踪 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复 GitHub issue #24 的微信群旧话题污染问题，并用 room 级焦点栈完全替代个人微信群既有 `wechat_group_topic_*` 话题追踪；旧 topic 表和历史数据不迁移、不保留。

**Architecture:** 新增 `WechatGroupFocusStore` / `WechatGroupFocusService` 作为个人微信群唯一话题内核，按 `room_id` 强隔离维护 `created / kept / pushed / returned / cleared / leaf / noop` 焦点栈事件。`WechatGroupChannel` 不再注入 `<wechat-group-topic>`，改为基于当前消息焦点选择 recent transcript 与 `<wechat-group-focus>`；Web 控制台从“话题追踪”替换为“焦点栈”。旧 `WechatGroupTopicStore`、`WechatGroupTopicService`、`wechat_group_topic_threads` 等 topic 数据完全废弃，不做历史迁移。

**Tech Stack:** Python、unittest、SQLite、现有 `channel/wechat_group/`、Web 控制台 `channel/web/`。

---

## 范围确认

- 只替代个人微信群通道里的 `wechat_group_topic_*` 话题追踪功能。
- 不改造 CowAgent 通用 Agent 会话恢复，不修改 `agent.memory.ConversationStore.load_messages()` 语义。
- 不修改其他渠道的 Agent 历史注入方式。
- 不迁移旧 `wechat_group_topic_threads`、`wechat_group_topic_message_refs`、`wechat_group_topic_summary_history` 数据。
- 新版本启动或首次使用焦点栈时，删除旧 `wechat_group_topics.db` 或清空旧 topic 表；旧历史话题从产品语义上消失。
- 群聊隔离是硬约束：焦点栈、焦点消息引用、焦点检索、Web API 必须始终按 `room_id` 过滤。

## 目标行为

issue #24 示例：

```text
用户A：难受 她不爱我了
用户B：xx不爱你了吗
用户B：截图
用户B：让gpt来帮忙了
bot：gpt帮你挽回还是帮你写分手信[吃瓜]
```

改造后：

- 当前 standalone @ 或普通独立触发不会自动注入旧焦点的 recent transcript。
- 机器人不应把“她不爱我了”旧焦点和“让gpt来帮忙了”合成一个回复上下文。
- “总结刚才 / 上面说的 / 继续刚才 / 引用某条消息 / 看这张图”等上下文依赖请求仍能读取当前群最近相关消息。
- 同一群内焦点栈可以保留多个未完成焦点，但 prompt 默认只注入当前命中的焦点；旧焦点只在用户明确回指时参与。
- 跨群绝不共享焦点帧，即使 `group_shared_session = true`。

## 焦点事件规则

事件定义：

- `created`: 当前 room 没有焦点栈，新建第一帧。
- `kept`: 当前消息命中栈顶焦点，更新 `last_seen_at` / `hit_count`。
- `pushed`: 当前消息是新独立焦点，压入栈顶。
- `returned`: 当前消息明确回指非栈顶焦点，pop 到被命中的旧焦点。
- `cleared`: 栈顶 stale 超过阈值，被清理。
- `leaf`: 当前消息是一次性请求，不创建新焦点，也不引用旧焦点。
- `noop`: 空消息、低信息消息或焦点关闭。

上下文依赖关键词：

```python
CONTEXTUAL_TOKENS = (
    "刚才", "上面", "前面", "之前", "继续", "接着", "总结",
    "这张", "这个", "这条", "那张", "那个", "那条",
    "图里", "图片", "截图", "引用", "谁说", "聊天记录", "什么意思",
)
```

standalone 判定：

- 没有引用消息。
- 不是图片/视频/文件理解请求。
- 当前文本不包含上下文依赖关键词。
- 当前文本去掉机器人 mention 后仍是独立请求。

standalone prompt 行为：

- 不注入旧 focus frame 的消息。
- 不注入 `<wechat-group-focus-history>`。
- 可创建新焦点或标记为 `leaf`，但本轮 recent transcript 只允许包含当前消息。

contextual prompt 行为：

- 引用消息优先使用引用对应归档消息。
- 显式“总结刚才/上面/继续”等请求可使用当前 room 最近消息。
- 如果命中已有焦点，只注入该焦点关联消息。
- 如果 returned 到旧焦点，只注入 returned 后的新栈顶焦点。

```python
def _default_data_root() -> str:
    return os.environ.get("COW_DATA_DIR") or os.path.join(os.path.expanduser("~"), ".cow")


def legacy_topic_db_path(data_root: str = "") -> str:
    root = os.path.expanduser(data_root or _default_data_root())
    return os.path.join(root, "wechat_group", "wechat_group_topics.db")


def discard_legacy_topic_data(data_root: str = "") -> bool:
    path = legacy_topic_db_path(data_root)
    if not os.path.exists(path):
        return False
    try:
        os.remove(path)
        return True
    except OSError:
        conn = sqlite3.connect(path, timeout=10)
        try:
            with conn:
                conn.execute("DROP TABLE IF EXISTS wechat_group_topic_threads")
                conn.execute("DROP TABLE IF EXISTS wechat_group_topic_message_refs")
                conn.execute("DROP TABLE IF EXISTS wechat_group_topic_summary_history")
            return True
        finally:
            conn.close()
```

- [ ] **Step 2: 实现关键词提取**

```python
def extract_focus_keywords(text: str, limit: int = 8) -> list[str]:
    value = normalize_query_text(text)
    tokens = re.findall(r"[0-9A-Za-z_\\-]{2,}|[\\u4e00-\\u9fff]{2,}", value)
    stopwords = {"一下", "帮忙", "看看", "这个", "那个", "就是", "可以", "是不是"}
    return unique tokens not in stopwords, max limit
```

要求：

- [ ] **Step 4: 实现焦点栈更新**

接口签名：`resolve_reply_focus(self, archive, msg, query: str, now: int | None = None) -> dict`

规则：

- 从 store 读取当前 `room_id` 栈。
- 从 archive 读取当前 room 最近 `wechat_group_focus_recent_message_limit` 条消息。
- 如果当前请求是 standalone 且关键词少于 `wechat_group_focus_min_keywords`，返回 `leaf`，`messages` 只包含当前消息对应 row。
- 如果栈为空且当前不是 leaf，创建第一帧。
- 如果关键词和栈顶有交集，`kept`。
- 如果关键词和非栈顶焦点有交集且当前文本有“回到/继续/刚才/之前”等回指词，`returned`。
- 否则 `pushed`。
- 超过 `wechat_group_focus_stack_depth` 时移除栈底，不压缩旧数据。
