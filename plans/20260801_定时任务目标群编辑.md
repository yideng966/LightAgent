# 定时任务目标群编辑计划

## 任务背景

修复 Web 控制台定时任务编辑能力：个人微信群通道的已创建任务只能保留原目标群，无法在编辑页面查看并切换到其他已选择的稳定群。

## 实施步骤

- [x] 检查工作区状态，定位定时任务编辑弹窗、保存接口与个人微信群稳定群数据源。
- [x] 在编辑弹窗中为个人微信群任务显示目标群下拉，并回填当前目标群。
- [x] 保存时同步更新稳定群、运行时群快照、群名和目标会话字段。
- [x] 补充聚焦回归测试，并同步中英文 Web 控制台文档和 `CHANGES.md`。
- [x] 运行 JavaScript 语法检查、聚焦测试、差异检查和必要的本地页面验证。

## 约束

- 仅修改 Web 控制台，不修改已归档的 `desktop/`。
- 通道类型继续保持只读，只允许个人微信群任务在已选择的稳定群之间切换目标。
- 当前任务目标即使暂时离线或已不在已选择群列表中，也必须保留显示，避免编辑时被意外清空。
- 不改变 scheduler 的执行、重试、稳定身份解析和其他通道行为。
- 不修改或提交工作区中与本任务无关的文件。

## 当前状态

已完成。

## 实际改动

- 定时任务编辑弹窗新增个人微信群目标群下拉，仅在 `channel_type = wechat_group` 时显示。
- 下拉复用 `/api/channels` 中的已选稳定群、runtime 快照和群名；当前任务目标不在列表或暂时离线时仍保留为当前选项。
- 保存目标切换时同步更新 `stable_receiver`、`runtime_receiver`、`receiver`、`receiver_name`、`is_group` 和 `notify_session_id`，并保留 `creator_stable_member_id`。
- Scheduler 更新接口允许稳定群存在时缺少 runtime 快照，由现有投递链路执行前恢复；新目标必须属于当前已选稳定群，切换后清除旧目标遗留的身份绑定错误状态。
- 同步更新中英文 Web 控制台文档、README、回归测试和 `CHANGES.md`。
