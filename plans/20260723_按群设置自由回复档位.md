# 按群设置自由回复档位实施计划

> **供 Agent 执行：** 必须使用 `superpowers:executing-plans` 按任务逐项实施，并以复选框回写进度；功能代码遵循 `superpowers:test-driven-development` 的 RED → GREEN → REFACTOR 顺序。

**目标：** 让每个已启用自由回复的稳定微信群可以独立选择安静、普通、活跃或高频档位，同时保留全局档位作为兼容默认值。

**架构：** 新增稳定群 ID 到档位的配置映射，由现有自由回复配置模块统一归一化和解析。评分器按当前 stable room ID 选择实际档位；Web 控制台在每个群勾选行中编辑映射，原四套 profile 继续作为全局共享模板。

**技术栈：** Python 3、`unittest`、原生 JavaScript、HTML/Tailwind CSS、现有 Web.py 配置接口。

```python
def normalize_wechat_group_free_reply_stable_room_activity_levels(raw_levels=None) -> dict:
    if not isinstance(raw_levels, dict):
        return {}
    normalized = {}
    for raw_room_id, raw_level in raw_levels.items():
        room_id = str(raw_room_id or "").strip()
        level = str(raw_level or "").strip()
        if room_id.startswith("wgr_") and level in FREE_REPLY_ACTIVITY_LEVELS:
            normalized[room_id] = level
    return normalized


def resolve_wechat_group_free_reply_activity_level(config, room_id) -> str:
    default_level = str(config.get("activity_level") or "normal").strip()
    if default_level not in FREE_REPLY_ACTIVITY_LEVELS:
        default_level = "normal"
    room_levels = config.get("stable_room_activity_levels")
    if not isinstance(room_levels, dict):
        return default_level
    room_level = str(room_levels.get(str(room_id or "").strip()) or "").strip()
    return room_level if room_level in FREE_REPLY_ACTIVITY_LEVELS else default_level
```

让 `get_wechat_group_free_reply_config()` 返回归一化后的 `stable_room_activity_levels`，并让 `evaluate_wechat_group_free_reply()` 使用解析函数得到 `level`。

```javascript
function syncWechatGroupFreeReplyRoomLevelState(checkbox) {
    const roomId = String(checkbox?.dataset?.wechatGroupFreeReplyRoomId || '');
    document.querySelectorAll('[data-wechat-group-free-reply-room-level]').forEach(select => {
        if (String(select.dataset.wechatGroupFreeReplyRoomLevel || '') === roomId) {
            select.disabled = !!checkbox.disabled || !checkbox.checked;
        }
    });
}
```
