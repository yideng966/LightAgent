# 发布 LightAgent 2.2.8

## 目标

发布 `v2.2.8` 补丁版本，将新部署默认回复不再主动使用 emoji 或微信文字表情的行为交付给用户，并通过标签推送触发 GitHub Release 与 Docker 多架构镜像编译工作流。

## 版本范围

- 基准标签：`v2.2.7`
- 目标标签：`v2.2.8`
- 主要变化：删除默认 Agent 提示和微信群内置人设中的微信文字表情引导，独立媒体表情包行为保持不变。

## 实施步骤

- [x] 核对 `v2.2.7..HEAD` 的提交与文件差异。
- [x] 确认远端不存在 `v2.2.8`，且 `origin/master` 没有待合并提交。
- [x] 新增 `docs/releases/v2.2.8.md` 中文发行说明。
- [x] 使用 `scripts/stamp_release_version.py` 同步 `cli/VERSION` 与 `pyproject.toml`。
- [x] 更新 `CHANGES.md` 并完成发行校验与定向回归测试。
- [x] 创建发行提交和附注标签 `v2.2.8`。
- [x] 将 `master` 与 `v2.2.8` 推送到 `origin`。

## 风险与边界

- 本版本只调整缺省提示，不覆盖已有工作区 `AGENT.md`、现有 `config.json` 或管理员保存的自定义人设。
- 微信文字表情属于回复正文；独立媒体表情包的自动收集、主动回复频率、检索、发送和 Web 配置不变。
- 本版本不修改数据库或消息渠道协议，不需要数据迁移。
- 按用户要求不执行全量回归，只运行本次功能定向测试、版本与发行合同校验。
- 标签推送成功即完成，不等待 GitHub Actions 或镜像构建终态。
- 不提交工作区中与本版本无关的未跟踪计划文件。

## 实施结果

- 已新增面向用户的 `docs/releases/v2.2.8.md`，内容只覆盖默认微信文字表情引导移除，并明确独立媒体表情包行为不变。
- 已使用 `scripts/stamp_release_version.py` 将 `cli/VERSION` 与 `pyproject.toml` 同步为 `2.2.8`。
- 发行说明校验、版本和 Docker 发布合同测试通过；本次功能定向测试 14 项通过，按用户要求未运行全量回归。
- 已创建简体中文发行提交和附注标签 `v2.2.8`，并将 `master` 与标签推送到 `origin`；按仓库规则不等待远端工作流终态。

## 剩余事项

无。按仓库规则不等待 GitHub Actions 或镜像构建终态。
