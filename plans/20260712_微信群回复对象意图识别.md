# 微信群回复对象意图识别实施计划

## 目标

降低微信群里 A 对 B 说话时机器人误把自己当成执行对象的概率，让 LLM 在请求前明确区分“发言人请求机器人”“发言人请求其他群友”“对全群闲聊/求助”。

## 范围

- 仅增强个人微信群当前轮 prompt 上下文与自由回复判定提示。
- 不新增独立 Agent、不改 sidecar 协议、不改变现有真实 @ 发送策略。
- 优先复用现有 `at_list`、`trigger_source`、`wechat_group_reply_policy_enabled` 与人性化上下文构建链路。

## 实际改动

- 新增 `build_wechat_group_addressee_policy_block()`：基于当前发言人、机器人 ID 和 `at_list` 生成回复对象策略块。
- `WechatGroupHumanizedContextBuilder` 在 reply policy 开启时注入 `<wechat-group-addressee-policy>`。
- 微信群通道降级上下文路径补齐 mention verification、addressee policy 与 reply policy。
- 自由回复 LLM judge prompt 补充 A 对 B、请求群友、两人私聊默认不接话的规则。
- 新增 `tests/test_wechat_group_addressee_policy.py` 覆盖策略块与 judge prompt。
