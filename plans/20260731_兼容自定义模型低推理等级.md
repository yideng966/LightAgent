# 兼容自定义模型低推理等级开发计划

## 背景

微信群图片或已匹配图片上下文会使用 `reasoning_effort=none` 作为请求级关闭思考标记。部分自定义 OpenAI 兼容端点只接受 `low`、`medium`、`high`，因此在解析请求时返回 HTTP 422。

## 目标

- 自定义 OpenAI 兼容端点实际收到 `reasoning_effort=low`。
- LightAgent 内部继续使用 `none` 标记请求级禁用思考，保持 `thinking={"type":"disabled"}` 控制和图片思考隔离。
- 原生 OpenAI 及其他 Provider 的现有请求参数不受影响。

## 实施步骤

1. 在 OpenAI 兼容适配器的自定义 Provider 出站边界转换推理等级。
2. 验证转换不修改原始 `request_options`，也不移除禁用思考控制。
3. 运行 OpenAI 兼容消息、模型回退、流式思考隔离和自由回复 Scorer 回归。
4. 更新项目规则与变更记录，并回写实际验证结果。
