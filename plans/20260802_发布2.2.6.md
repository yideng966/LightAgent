# 发布 LightAgent 2.2.6

## 目标

发布 `v2.2.6` 补丁版本，将微信群技能新增、修改和删除纳入可配置的管理员门禁，并通过标签推送触发 GitHub Release 与 Docker 多架构镜像编译工作流。

## 版本范围

- 基准标签：`v2.2.5`
- 目标标签：`v2.2.6`
- 主要变化：新增默认开启的 `skill_manage`，统一保护聊天技能变更命令和 Agent 对 workspace 技能目录的直接修改。

## 实施步骤

- [x] 核对 `v2.2.5..HEAD` 的提交与文件差异。
- [x] 确认远端不存在 `v2.2.6`，且发布工作流由 `v*` 标签推送触发。
- [x] 新增 `docs/releases/v2.2.6.md` 中文发行说明。
- [x] 使用 `scripts/stamp_release_version.py` 同步 `cli/VERSION` 与 `pyproject.toml`。
- [x] 更新 `CHANGES.md` 并完成发行校验与相关回归测试。
- [x] 创建发行提交和附注标签 `v2.2.6`。
- [x] 将 `master` 与 `v2.2.6` 推送到 `origin`，触发远端编译。

## 风险与边界

- `skill_manage` 对缺少该字段的旧配置默认开启，以保持技能管理的保守安全边界。
- 本版本不修改数据库或微信群 sidecar 协议，不需要数据迁移。
- 标签推送成功且工作流触发条件确认即完成；按仓库规则不等待远端编译终态。
- 不提交工作区中与本版本无关的未跟踪计划文件。
