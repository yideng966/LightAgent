# 停止桌面端维护计划

## 背景

LightAgent 的核心运行入口是 Python 后端 `app.py`，Web 控制台、CLI、Docker 和各消息渠道均继续依赖该入口。`desktop/` 是在核心后端之外提供的 Electron 桌面壳，现决定停止维护，避免桌面安装包打包失败继续阻塞版本发布。

`v2.1.9` 标签已经推送，不能移动或覆盖。该标签触发的桌面工作流已按新决策取消，Docker 基础版与 `skills-full` 构建继续运行。后续调整通过新补丁版本 `v2.1.10` 发布。

## 目标

- 保留并继续维护 `app.py`、Web 控制台、CLI、消息渠道和 Docker 镜像。
- 将 `desktop/` 标记为历史归档，不再开发功能、修复问题或提供安装包。
- 移除 GitHub Actions 中的 Electron、PyInstaller 和桌面安装包构建发布步骤。
- 保留标签触发的 GitHub Release，并仅使用版本化发行说明创建或更新 Release。
- 保留标签触发的 Docker Hub 与 GHCR 镜像发布。

## 修改边界

- 不删除 `desktop/` 历史源码，不改动其运行逻辑。
- 不删除、移动或覆盖任何既有标签和 Release。
- 不改动 `app.py`、Python 后端依赖或 Docker 镜像能力。
- 不把工作区既有的 `plans/20260727_内置更新与重启功能开发计划.md` 删除状态纳入本次提交。
