# 微信群自由回复机器人追问误拒修复计划

## 任务背景

自由回复 legacy Judge 将“还有哪里强？”判为“未明确指向机器人或全群”并拒绝，但该消息紧跟机器人已真实发送的回复，属于省略 `@` 和机器人名称的自然追问。

## 根因

- 本地收件人分析已经产出 `target_kind=bot`、`is_immediate_bot_followup=true`。
- legacy Judge 提示词仍要求文本明确指向机器人或全群，没有说明即时追问本身就是明确的机器人目标。
- 二次判定可因此覆盖确定性的近场收件人证据，产生误拒绝。

## 实施范围

- [ ] 补充“机器人回复后发送省略式短问句”的回归测试。
- [ ] 让无本地抑制的 `is_immediate_bot_followup` 在 legacy Judge 前确定性放行。
- [ ] 修正 legacy Judge 提示词，明确机器人即时追问不需要再次 `@` 或点名。
- [ ] 保持群友间短问句硬抑制、敏感内容、禁言、黑名单、冷却和频率限制不变。
- [ ] 运行自由回复 Judge、本地评分和 worker 定向回归。
- [ ] 回写实际改动、验证结果与剩余事项。
