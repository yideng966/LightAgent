# 发布 LightAgent 2.2.7

## 目标

发布 `v2.2.7` 补丁版本，将 Agent 深度思考启停、四档强度和 Provider 协议适配交付给用户，并通过标签推送触发 GitHub Release 与 Docker 多架构镜像编译工作流。

## 版本范围

- 基准标签：`v2.2.6`
- 目标标签：`v2.2.7`
- 主要变化：统一深度思考配置语义，由 Provider 按实际协议适配启停和 `low/medium/high/max` 四档强度。

## 实施步骤

- [x] 核对 `v2.2.6..HEAD` 的提交与文件差异。
- [x] 确认远端不存在 `v2.2.7`，且 `origin/master` 没有待合并的新提交。
- [x] 新增 `docs/releases/v2.2.7.md` 中文发行说明。
- [x] 使用 `scripts/stamp_release_version.py` 同步 `cli/VERSION` 与 `pyproject.toml`。
- [x] 更新 `CHANGES.md` 并完成发行校验与相关回归测试。
- [x] 创建发行提交和附注标签 `v2.2.7`。
- [x] 将 `master` 与 `v2.2.7` 推送到 `origin`，触发远端编译。

## 风险与边界

- 四档强度是跨 Provider 的相对等级，不承诺不同厂商消耗相同的推理 token。
- 固定推理模型可能无法关闭思考；未知或未配置协议的 Custom Provider 默认不发送思考参数。
- 本版本不修改数据库、消息渠道协议或非文本模型路由，不需要数据迁移。
- 标签推送成功且工作流触发条件确认即完成；按仓库规则不等待远端编译终态。
- 不提交工作区中与本版本无关的未跟踪计划文件。

- 已使用 `scripts/stamp_release_version.py` 将 `cli/VERSION` 与 `pyproject.toml` 同步为 `2.2.7`。
