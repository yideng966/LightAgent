> **状态：** 执行中

## 1. 发布目标

将 `v2.1.18..master` 中已验证的流式思考过程泄漏修复发布为稳定版本 `v2.1.19`。发布提交包含版本文件和 `docs/releases/v2.1.19.md`，再创建并推送附注标签；标签用于触发 GitHub Release 与 Docker 多架构镜像工作流，不以远端构建终态阻塞本次交付。

## 2. 发布范围

本次发行只包含一项用户可感知修复：部分模型或兼容代理把 `<think>` 思考块放入流式 `content` 且标签跨分片时，IM 渠道不再发送或持久化思考内容与残余标签。Web 思考展示和标准 `reasoning_content` 行为保持不变。

没有配置格式、数据库结构或默认行为的破坏性变化。
