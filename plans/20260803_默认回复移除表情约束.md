# 默认回复移除表情约束实施计划

## 背景

当前新工作区的 `AGENT.md`、Agent 通用提示、首次初始化提示和微信群默认人设均包含主动使用 emoji 或微信文字表情的引导。多个默认约束叠加后，模型可能在多数回复末尾重复使用 `[破涕为笑]`、`[吃瓜]` 等微信文字表情。

## 目标

- 新部署和新建工作区默认不要求 Agent 使用 emoji 或微信文字表情。
- 保留用户通过自定义人设明确启用表情的能力。
- 独立媒体表情包的自动收集、主动回复频率、检索和发送行为保持不变。
- 不覆盖现有用户的 `config.json` 和已有工作区 `AGENT.md`。

## 实施步骤

- [x] 核对默认提示来源、配置回退和现有测试。
- [x] 删除默认 `AGENT.md`、通用系统提示和首次初始化提示中的 emoji 使用要求。
- [x] 移除微信群内置人设中的默认文字表情引导。
- [x] 确认表情包配置、回复策略和 Web 管理行为保持不变。
- [x] 补充默认行为回归测试并更新中英文相关文档、`CHANGES.md`。
- [x] 运行定向测试、语法检查和差异检查。

## 验证范围

- 新工作区生成的中英文 `AGENT.md` 不包含主动使用 emoji 的约束。
- Agent 通用系统提示和首次初始化提示不再主动要求 emoji。
- 微信群内置人设不包含 `[吃瓜]`、`[呲牙]`、`[捂脸]` 等默认文字表情示例。
- `wechat_group_sticker_reply_percent` 及表情包的配置模板、回复策略和 Web 默认值保持原值 `20`。
- 表情包自动收集、检索和发送能力不受影响。

已完成。
