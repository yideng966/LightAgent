# 微信群自然接梗与表情包回复 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 CowAgent 在已开启自由回复的微信群里，对明显玩梗、吐槽、笑点和表情包请求自然接话，并在合适时复用现有表情包工具发送本地或在线表情包。

**Architecture:** 不新增独立回复引擎，不绕过 `ChatChannel` / `Bridge` / Agent 主链路。先增强 `wechat_group_free_reply.py` 的本地评分和触发理由，再增强 LLM judge 与微信群回复策略 prompt，让已通过自由回复的上下文更明确地鼓励短句自然接梗，并允许模型按现有 `wechat_group_sticker_search` / `wechat_group_sticker_send` 工具发送一张表情包。

**Tech Stack:** Python、`unittest`、CowAgent 微信群通道、现有 `WechatGroupFreeReplyWorkerPool`、`WechatGroupHumanizedContextBuilder`、`WechatGroupStickerService`、Agent 工具系统。

---

## 范围

- 只对 `wechat_group_free_reply_enabled = true` 且命中 `wechat_group_free_reply_room_ids` 或 `wechat_group_free_reply_names` 的微信群生效。
- 非 @ 普通群消息可以自然接梗；未开启自由回复的群保持沉默。
- `@ bot`、引用 bot、图片理解、文件发送、知识库和记忆写入权限不改变。
- 表情包默认文字优先，只在明显适合时发送一张；继续受当前群绑定、在线域名白名单、大小限制、冷却和日限约束。

```python
def _looks_like_sticker_request(text: str) -> bool:
    return bool(
        re.search(
            r"(表情包|表情|梗图|斗图|gif|GIF|动图|来张图|来个图|发张图|发个图|整张图|整一个图)",
            text or "",
            re.IGNORECASE,
        )
    )


def _looks_like_banter(text: str) -> bool:
    return bool(
        re.search(
            r"(笑死|绷不住|蚌埠住|破防|离谱|抽象|逆天|乐|哈哈哈|hhh|草|卧槽|吐槽|好家伙|典|急了|整活|活了|不愧是|太对了|这也行|烂活|名场面|赢麻了|上强度|电子榨菜|遥遥领先|尊嘟假嘟|栓q|泰裤辣|绝绝子)",
            text or "",
            re.IGNORECASE,
        )
    )


def _plain_message_text(row) -> str:
    if isinstance(row, dict):
        return _normalize_text(row.get("text") or row.get("content") or "")
    return _normalize_text(str(row or ""))


def _sender_key(row) -> str:
    if not isinstance(row, dict):
        return ""
    return str(row.get("sender_id") or row.get("sender_nickname") or row.get("sender_name") or "").strip()


def _looks_like_repeater_message(text: str, recent_messages=None) -> bool:
    value = _normalize_text(text)
    if not value or not _looks_like_banter(value):
        return False
    senders = set()
    for row in recent_messages or []:
        if _plain_message_text(row) == value:
            sender = _sender_key(row)
            if sender:
                senders.add(sender)
    return len(senders) >= 2
```

## 风险与回退

- 触发过频风险：由 `wechat_group_free_reply_activity_level`、各 profile 阈值、LLM judge、冷却、小时上限和连续上限控制；本次不改变默认 `wechat_group_free_reply_enabled = false`。
- 表情包滥发风险：默认文字优先，表情包发送继续受 `wechat_group_sticker_cooldown_seconds`、`wechat_group_sticker_daily_send_limit` 和在线域名白名单控制。
- 跨群泄露风险：表情包工具仍按当前 `room_id` 绑定；在线候选只在当前搜索结果中使用。
- 回退方式：撤回本次代码改动，或将 `wechat_group_free_reply_enabled` 关闭；已下载在线表情包缓存不影响消息链路。
