# 微信群管理员权限 Implementation Plan

> **面向执行 Agent 的要求：** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans` 按任务逐项实施。步骤使用复选框语法跟踪进度；每完成一个任务后回写本文档的执行状态、实际改动和验证结果。

**Goal:** 在个人微信群通道中新增按 `room_id + sender_id` 生效的群管理员配置、Web 控制台管理 UI，以及面向持久化/写入类能力的管理员门禁。

**Architecture:** 管理员身份由 `room_id + sender_id` 精确匹配，配置和纯函数放在 `channel/wechat_group/wechat_group_permissions.py`。Web 控制台复用现有微信群设置页与归档成员数据源；通道层在 `_generate_reply()` 进入 Agent 前做高风险意图拒绝，`bridge/agent_bridge.py` 在当前 turn 临时过滤高风险工具，Prompt 仅作为辅助提示。

**Tech Stack:** Python `unittest`、现有 `web.py` Web API、`channel/wechat_group` 通道层、`bridge/agent_bridge.py` Agent 工具过滤、Web 控制台原生 JavaScript/Tailwind class。

## 范围边界

- 管理员权限按 `room_id + sender_id` 生效，不做全局自动放权。
- 新 UI 写入 `wechat_group_admin_members`，旧 `wechat_group_admin_sender_ids` 只作为兼容 fallback。
- 删除“群聊开关”页的群名兜底 textarea；不删除已有配置文件中的旧字段，避免升级后丢失配置。
- 本次不扩展 Wechaty sidecar 协议；成员检索使用本地归档 `WechatGroupArchive.list_members()`。
- 普通群成员仍可问答、查询、总结、读取知识/记忆、图片理解和公开资料讨论。
- 管理员门禁只约束持久化写入、配置修改、文件修改、学习沉淀、定时任务和素材管理类能力。
- 管理员门禁不是隐藏配置项。所有受控能力必须在 Web UI 中以“权限矩阵”形式展示，并允许用户逐项勾选启用/关闭门禁。
- 每个受控能力在 UI 中必须展示：能力名称、启用复选框、普通成员被限制的行为、仍允许的行为、示例话术、执行门禁层级、受影响工具/配置/数据对象。

## 管理员受控功能矩阵

UI 需要把以下内部逻辑完整暴露给用户。复选框含义统一为：**勾选后，该能力只有当前群管理员可触发；取消勾选后，普通成员也可触发该能力，但仍受原有工具安全限制约束。**

| 权限 ID | UI 名称 | 勾选后普通成员不能做什么 | 普通成员仍允许做什么 | UI 示例话术 | 门禁层级 | 受影响对象 |
| --- | --- | --- | --- | --- | --- | --- |
| `knowledge_write` | 写入知识库 | 把资料保存/导入/整理到知识库或知识页 | 查询、引用、总结已有知识库内容 | “保存到知识库”“把这个资料学习一下” | 通道意图识别、工具过滤、Prompt 提示 | `knowledge/**`、`write`、`edit`、知识库索引 |
| `memory_write` | 写入全局永久记忆 | 写入 `MEMORY.md`、每日记忆或全局长期记忆 | 搜索、读取、基于记忆回答 | “加入你的记忆库”“以后记住这件事” | 通道意图识别、工具过滤、Prompt 提示 | `MEMORY.md`、`memory/**`、`write`、`edit` |
| `wechat_group_memory_write` | 写入/禁用群永久记忆 | 新增、更新、禁用当前群永久记忆 | 查询当前群记忆、基于群记忆回答 | “记到本群永久记忆”“删掉这条群记忆” | 通道意图识别、微信群工具过滤、Prompt 提示 | `wechat_group_group_memories`、群记忆服务 |
| `wechat_group_profile_write` | 管理群友画像 | 新增/修改群友画像、别名、常用词、发言风格 | 查询群友画像、基于画像调整称呼 | “把张三画像改成产品负责人”“给他加个别名” | 通道意图识别、微信群工具过滤、Prompt 提示 | `wechat_group_global_profiles`、画像 name records |
| `wechat_group_learning` | 触发微信群学习沉淀 | 手动触发群学习任务、从归档批量沉淀画像/群记忆 | 普通聊天过程中被动归档消息 | “跑一次群学习”“把最近聊天沉淀一下” | 通道意图识别、Web API 保护、Prompt 提示 | `WechatGroupLearner`、learning runs |
| `self_evolution` | 触发自主进化 | 要求机器人自我进化、沉淀技能、修改自身长期能力 | 普通建议、反馈和问答 | “你进化一下”“把这次经验沉淀成技能” | 通道意图识别、工具过滤、Prompt 提示 | `agent/evolution`、`evolution_undo` |
| `workspace_write` | 写入/编辑工作区文件 | 创建、覆盖、编辑 workspace 文件或通过 shell 修改文件 | 读取公开/允许读取的文件摘要，给手动操作建议 | “整理成 md 文件”“帮我改这个文件” | 通道意图识别、工具过滤、Prompt 提示 | `write`、`edit`、`bash`、`agent_workspace` |
| `wechat_group_config` | 修改微信群配置/人设 | 通过群聊修改人设、群配置、管理员、运行状态 | 询问当前配置含义、请求说明 | “修改人设”“把这个群设成自由回复” | 通道意图识别、Prompt 提示、配置 API 保护 | `wechat_group_*` 配置、人设 prompt |
| `scheduler_write` | 新增/修改定时任务 | 创建、更新、删除定时任务或提醒 | 查询任务说明、让机器人解释如何手动设置 | “每天九点提醒我”“删除这个定时任务” | 通道意图识别、工具过滤、Prompt 提示 | `scheduler` 工具、任务存储 |
| `sticker_manage` | 管理表情包/素材库 | 收藏、禁用、改写表情包/素材库元数据 | 搜索和发送已启用表情包 | “禁用这个表情”“把这张图收进素材库” | 通道意图识别、微信群工具过滤、Prompt 提示 | `wechat_group_stickers`、素材目录 |

UI 展示要求：

- 权限矩阵放在“群与管理员”页的管理员管理区下方。
- 每一项用一行或紧凑卡片展示，左侧是复选框和名称，右侧展示“限制行为 / 仍允许 / 示例 / 门禁层级 / 影响对象”。
- 默认折叠长详情，只显示名称、摘要和复选框；点击“详情”展开完整逻辑，避免页面一次性过载。
- 每个复选框旁必须有明确状态文案：`已启用门禁` / `未启用门禁`。
- 保存按钮保存的是当前所有权限项的勾选状态，而不是只保存被改动项。
- UI 不使用“高风险能力”等模糊词替代具体能力，必须逐项写清楚能力含义。

import unittest

from config import conf


class WechatGroupPermissionsTest(unittest.TestCase):
    def setUp(self):
        self._original = {
            "wechat_group_admin_members": conf().get("wechat_group_admin_members"),
            "wechat_group_admin_sender_ids": conf().get("wechat_group_admin_sender_ids"),
            "wechat_group_admin_required_permissions": conf().get("wechat_group_admin_required_permissions"),
        }

    def tearDown(self):
        for key, value in self._original.items():
            if value is None:
                conf().pop(key, None)
            else:
                conf()[key] = value

    def test_admin_is_scoped_by_room_and_sender(self):
        from channel.wechat_group.wechat_group_permissions import is_wechat_group_admin

        conf()["wechat_group_admin_members"] = [
            {
                "room_id": "room@@a",
                "room_name": "A 群",
                "sender_id": "wxid_admin",
                "sender_nickname": "Alice",
                "wechat_id": "alice_wechat",
            }
        ]
        conf()["wechat_group_admin_sender_ids"] = []

        self.assertTrue(is_wechat_group_admin("room@@a", "wxid_admin"))
        self.assertFalse(is_wechat_group_admin("room@@b", "wxid_admin"))
        self.assertFalse(is_wechat_group_admin("room@@a", "wxid_other"))

    def test_legacy_sender_ids_are_used_only_when_new_members_empty(self):
        from channel.wechat_group.wechat_group_permissions import is_wechat_group_admin

        conf()["wechat_group_admin_members"] = []
        conf()["wechat_group_admin_sender_ids"] = ["wxid_legacy"]

        self.assertTrue(is_wechat_group_admin("room@@any", "wxid_legacy"))
        self.assertFalse(is_wechat_group_admin("room@@any", "wxid_other"))

        conf()["wechat_group_admin_members"] = [{"room_id": "room@@a", "sender_id": "wxid_admin"}]
        self.assertFalse(is_wechat_group_admin("room@@any", "wxid_legacy"))

    def test_normalize_admin_members_deduplicates_room_sender_pairs(self):
        from channel.wechat_group.wechat_group_permissions import normalize_wechat_group_admin_members

        members = normalize_wechat_group_admin_members([
            {"room_id": " room@@a ", "sender_id": " wxid_admin ", "sender_nickname": "Alice"},
            {"room_id": "room@@a", "sender_id": "wxid_admin", "sender_nickname": "Alice 2"},
            {"room_id": "", "sender_id": "wxid_empty"},
            {"room_id": "room@@b", "sender_id": ""},
        ])

        self.assertEqual(1, len(members))
        self.assertEqual("room@@a", members[0]["room_id"])
        self.assertEqual("wxid_admin", members[0]["sender_id"])
        self.assertEqual("Alice", members[0]["sender_nickname"])

    def test_default_required_permissions_are_enabled(self):
        from channel.wechat_group.wechat_group_permissions import (
            get_wechat_group_admin_permission_definitions,
            get_wechat_group_admin_required_permissions,
        )

        conf().pop("wechat_group_admin_required_permissions", None)
        permissions = get_wechat_group_admin_required_permissions()
        definitions = get_wechat_group_admin_permission_definitions()

        self.assertTrue(permissions["knowledge_write"])
        self.assertTrue(permissions["memory_write"])
        self.assertTrue(permissions["wechat_group_memory_write"])
        self.assertTrue(permissions["workspace_write"])
        self.assertEqual(10, len(definitions))
        first = definitions[0]
        self.assertIn("id", first)
        self.assertIn("label", first)
        self.assertIn("summary", first)
        self.assertIn("blocked_behavior", first)
        self.assertIn("allowed_behavior", first)
        self.assertIn("examples", first)
        self.assertIn("guard_layers", first)
        self.assertIn("affected_objects", first)
        self.assertIn("default_enabled", first)

    def test_detects_persistent_write_intent(self):

        detected = detect_wechat_group_admin_required_permissions(
            "整理成 md 文档存入永久记忆以及知识库中"
        )

        self.assertIn("knowledge_write", detected)
        self.assertIn("memory_write", detected)
        self.assertIn("workspace_write", detected)

    def test_tool_filter_removes_non_admin_write_tools(self):

        class FakeTool:
            def __init__(self, name):

            config={
                "wechat_group_admin_members": [{"room_id": "room@@a", "sender_id": "wxid_admin"}],
                "wechat_group_admin_required_permissions": {
                    "workspace_write": True,
                    "scheduler_write": True,
                },
            },
        )

        self.assertEqual(["read"], [tool.name for tool in filtered])

def _cfg(config: Optional[Dict[str, Any]] = None) -> Dict[str, Any]:
    return config if isinstance(config, dict) else conf()


def _clean_text(value: Any) -> str:
    return str(value or "").strip()


def normalize_wechat_group_admin_members(value: Any) -> List[Dict[str, str]]:
    if not isinstance(value, list):
        return []
    result: List[Dict[str, str]] = []
    seen = set()
    for raw in value:
        if not isinstance(raw, dict):
            continue
        room_id = _clean_text(raw.get("room_id"))
        sender_id = _clean_text(raw.get("sender_id"))
        if not room_id or not sender_id:
            continue
        key = (room_id, sender_id)
        if key in seen:
            continue
        seen.add(key)
        result.append({
            "room_id": room_id,
            "room_name": _clean_text(raw.get("room_name")),
            "sender_id": sender_id,
            "sender_nickname": _clean_text(raw.get("sender_nickname")),
            "wechat_id": _clean_text(raw.get("wechat_id")),
        })
    return result


def get_wechat_group_admin_members(config: Optional[Dict[str, Any]] = None) -> List[Dict[str, str]]:
    return normalize_wechat_group_admin_members(_cfg(config).get("wechat_group_admin_members", []))


def get_wechat_group_admin_required_permissions(
    config: Optional[Dict[str, Any]] = None,
) -> Dict[str, bool]:
    raw = _cfg(config).get("wechat_group_admin_required_permissions", {})
    normalized = dict(DEFAULT_WECHAT_GROUP_ADMIN_REQUIRED_PERMISSIONS)
    if isinstance(raw, dict):
        for key in normalized:
            if key in raw:
                normalized[key] = bool(raw.get(key))
    return normalized


def get_wechat_group_admin_permission_definitions() -> List[Dict[str, Any]]:
    permissions = get_wechat_group_admin_required_permissions()
    result = []
    for item in WECHAT_GROUP_ADMIN_PERMISSION_DEFINITIONS:
        permission_id = item["id"]
        enriched = dict(item)
        enriched["default_enabled"] = DEFAULT_WECHAT_GROUP_ADMIN_REQUIRED_PERMISSIONS.get(permission_id, True)
        enriched["enabled"] = permissions.get(permission_id, True)
        result.append(enriched)
    return result


def is_wechat_group_admin(
    room_id: Any,
    sender_id: Any,
    config: Optional[Dict[str, Any]] = None,
) -> bool:
    room_text = _clean_text(room_id)
    sender_text = _clean_text(sender_id)
    if not room_text or not sender_text:
        return False
    cfg = _cfg(config)
    members = get_wechat_group_admin_members(cfg)
    if members:
        return any(
            item["room_id"] == room_text and item["sender_id"] == sender_text
            for item in members
        )
    legacy_ids = cfg.get("wechat_group_admin_sender_ids", []) or []
    return sender_text in {str(item).strip() for item in legacy_ids if str(item).strip()}

def build_wechat_group_admin_policy_block(
    room_id: Any,
    sender_id: Any,
    config: Optional[Dict[str, Any]] = None,
) -> str:
    is_admin = is_wechat_group_admin(room_id, sender_id, config=config)
    permissions = get_wechat_group_admin_required_permissions(config)
    protected = [
        PERMISSION_LABELS_ZH[key]
        for key, enabled in permissions.items()
        if enabled and key in PERMISSION_LABELS_ZH

    return "\n".join([
        "<wechat-group-admin-policy>",
        "current_sender_is_admin: {}".format("true" if is_admin else "false"),
        "admin_scope: room_id + sender_id",
        "admin_required_permissions: {}".format("、".join(protected) if protected else "无"),

        "</wechat-group-admin-policy>",
    ])


def filter_wechat_group_tools_for_permissions(
    tools: Iterable[Any],
    room_id: Any,
    sender_id: Any,
    config: Optional[Dict[str, Any]] = None,
) -> List[Any]:
    tool_list = list(tools or [])
    if is_wechat_group_admin(room_id, sender_id, config=config):
        return tool_list
    permissions = get_wechat_group_admin_required_permissions(config)
    blocked_names = set()
    if permissions.get("workspace_write"):
        blocked_names.update({"write", "edit", "bash"})
    if permissions.get("scheduler_write"):
        blocked_names.add("scheduler")
    if permissions.get("self_evolution"):
        blocked_names.add("evolution_undo")
    return [tool for tool in tool_list if getattr(tool, "name", "") not in blocked_names]

class WechatGroupMembersHandler:
    def GET(self):
        _require_auth()
        try:
            params = web.input(room_id="", q="", limit="20")
            room_id = str(params.room_id or "").strip()
            if not room_id:
                raise ValueError("room_id is required")
            limit = self._to_int(params.limit, 20)
            members = self._get_archive().list_members(
                room_id,
                query=params.q or "",
                limit=limit,
            )
            return self._json({"status": "success", "members": members})
        except Exception as e:
            logger.error(f"[WebChannel] WechatGroupMembers GET error: {e}")
            return self._json({"status": "error", "message": str(e)})

    @staticmethod
    def _get_archive():
        running = WechatGroupQrHandler._get_running_channel()
        if running and hasattr(running, "archive"):
            return running.archive
        from channel.wechat_group.wechat_group_archive import WechatGroupArchive
        return WechatGroupArchive()

    @staticmethod
    def _json(payload):
        web.header("Content-Type", "application/json; charset=utf-8")
        return json.dumps(payload, ensure_ascii=False)

    @staticmethod
    def _to_int(value, default):
        try:
            return min(max(int(value), 1), 100)
        except Exception:
            return default

function searchGroupsAdminMembers() {

    const query = document.getElementById('groups-admin-member-query')?.value || '';
    groupsAdminState.roomId = roomId;
    groupsAdminState.query = query;

        groupsAdminState.members = [];
        renderGroupsView();
        return;
    }
    groupsAdminState.loading = true;
    renderGroupsView();
    fetch(`/api/wechat-group/members?room_id=${encodeURIComponent(roomId)}&q=${encodeURIComponent(query)}&limit=20`)
        .then(r => r.json())
        .then(data => {
            groupsAdminState.members = data.status === 'success' ? (data.members || []) : [];
        })
        .catch(() => { groupsAdminState.members = []; })
        .finally(() => {
            groupsAdminState.loading = false;
            renderGroupsView();
        });
}

function addGroupsSelectedAdmins() {
    const ch = getWechatGroupChannel();
    if (!ch) return;
    const extra = ch.extra || {};
    const roomId = groupsAdminState.roomId || document.getElementById('groups-admin-room')?.value || '';
    const selected = groupsAdminState.selectedSenderIds || new Set();
    const rooms = Array.isArray(extra.rooms) ? extra.rooms : [];
    const room = rooms.find(item => String(item.id || '') === roomId) || {};
    const current = Array.isArray(extra.admin?.members) ? extra.admin.members : [];
    const byKey = new Map(current.map(item => [`${item.room_id}::${item.sender_id}`, item]));
    (groupsAdminState.members || []).forEach(member => {
        const senderId = String(member.sender_id || '');
        if (!selected.has(senderId)) return;
        byKey.set(`${roomId}::${senderId}`, {
            room_id: roomId,
            room_name: String(room.name || ''),
            sender_id: senderId,
            sender_nickname: String(member.sender_nickname || senderId),
            wechat_id: String(member.wechat_id || ''),
        });
    });
    extra.admin = extra.admin || {};
    extra.admin.members = Array.from(byKey.values());
    groupsAdminState.selectedSenderIds = new Set();
    renderGroupsView();
}
