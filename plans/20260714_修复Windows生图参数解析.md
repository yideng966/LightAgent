# 修复 Windows 生图参数解析

## 背景

2026-07-14 的运行日志显示，Agent 在 Windows 上按 `skills/image-generation/SKILL.md` 的示例调用 `generate.py` 时返回：

```text
Invalid JSON: Expecting value: line 1 column 1 (char 0)
```

当前 `bash` 工具在 Windows 使用 `cmd.exe`，而技能示例使用类 Unix 的单引号包裹 JSON。`cmd.exe` 不把单引号视为参数定界符，JSON 会被拆成多个参数且双引号被命令行解析移除，导致 `generate.py` 在请求生图服务前解析失败。

## 实施范围

- [x] 为 `skills/image-generation/scripts/generate.py` 增加从 UTF-8 JSON 文件读取参数的入口，同时保留原有内联 JSON 兼容。
- [x] 更新 `skills/image-generation/SKILL.md`，Windows 明确使用 `write` 工具创建临时 JSON 文件，再通过 `--json-file` 调用脚本；Linux/macOS 保留内联 JSON 示例。
- [x] 增加参数解析回归测试，覆盖 JSON 文件成功、文件错误和旧入口兼容。
- [x] 更新 `CHANGES.md` 并运行定向测试。

## 风险与回退

- 改动只扩展 CLI 参数读取，不改变 Provider 路由和图片请求逻辑。
- 原有 `python generate.py '<json_args>'` 入口继续可用。
- 如需回退，移除 `--json-file` 分支和技能中的 Windows 专用说明即可。
