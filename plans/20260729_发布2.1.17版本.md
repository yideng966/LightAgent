> **状态：** 已完成

## 1. 发布目标

将 `v2.1.16..master` 的已验证变更发布为稳定版本 `v2.1.17`，创建版本化发行说明、附注 Git 标签和 GitHub Release。发布提交必须先包含 `docs/releases/v2.1.17.md`，再创建并推送标签，不使用强制推送，也不等待 Docker 镜像构建作为本任务完成条件。

## 2. 变更基线

本次版本范围包含 3 个提交：

| 提交 | 用户可感知变更 |
| --- | --- |
| `0720f734` | 入群欢迎和离群通知在缺少配置键时默认开启，显式关闭仍优先 |
| `1af418b4` | 修复无前导空格的扫码入群系统文案未触发欢迎 |
| `e8e87d88` | 优化群永久记忆调度、历史续跑、严格召回、运行诊断和 Web 管理入口 |

核对结果：

- 本地 `master` 与 `origin/master` 一致，发布前工作区干净。
- 最新稳定标签和 GitHub Release 均为 `v2.1.16`，`v2.1.17` 尚不存在。
- 3 个提交均无 GitHub 关联 PR；同期关闭 Issue 已核对，没有为本次提交建立可确认的自动关联。
- 本次没有模型、配置格式或数据库正文迁移；新增 SQLite 状态表和字段由现有幂等初始化逻辑处理。
- 进退群开关缺键默认值发生变化，需要在发行说明中单列破坏性变更和关闭迁移方式。

## 3. 发布内容

发行说明按用户价值归并为：

1. 群永久记忆统一归入「管理 -> 记忆 -> 群记忆」，补齐内容、生成运行和召回测试。
2. 群记忆生成使用持久化调度、独立历史断点、失败退避和受控结构修复。
3. 进退群通知全局开关默认开启，并说明旧配置缺键时的迁移方式。
4. 修复扫码入群系统文案兼容性，不放宽普通文本和跨群事件门禁。

不写入 Release 的内容：内部文件清单、提交哈希、测试数量、开发过程、远端群数据、未完成路线图和任何凭据。

## 6. 回退边界

- 标签推送前发现问题：修改发行说明或版本文件并重新校验，不创建标签。

- 只有标签指向错误提交时才考虑删除并重建；禁止默认强制移动已发布标签。
