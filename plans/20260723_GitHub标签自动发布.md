# GitHub 标签自动发布计划

## 目标

- 推送 `v*` 标签时，自动触发 Docker Hub 与 GHCR 镜像构建发布。
- 保留 `master` 分支推送更新 `latest` 镜像的现有行为。
- 保留手动触发入口，便于发布失败后重试。
- 将仓库条件、镜像路径与 GHCR package-name 统一为 LightAgent 当前仓库标识。

## 已确认口径

- GitHub 仓库：`yideng966/LightAgent`。
- Docker Hub 镜像：`yideng966/lightagent`。
- GHCR 镜像：`ghcr.io/yideng966/lightagent`。
- 版本标签：`v*`，例如 `v2.1.0`。
- Cloudflare R2 bucket 与 D1 数据库名称不在本次修改范围内。
- 桌面发布工作流 `release.yml` 已支持 `v*` 标签，不做修改。
