# 模型渠道限流自动切换实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 当 Agent 主模型遇到 429、408、5xx、timeout、rate limit 等临时故障时，自动尝试配置的备用模型渠道；全部失败后不把底层错误发到微信群，只有强制回复场景才发送脱敏兜底文案。

**架构：** 在 `bridge/agent_bridge.py` 的 `AgentLLMModel` 层实现候选模型渠道轮询，复用现有 `create_bot()` 与 `add_openai_compatible_support()`，不绕过 `Bridge.fetch_agent_reply()`。在 Web 模型管理页通过 `/api/models` 读写 `model_fallbacks`，让备用模型渠道可视化配置。在微信群发送层拦截临时模型故障类 `ReplyType.ERROR`，非强制回复静默，强制回复发送固定脱敏提示。

**Tech Stack:** Python、unittest、现有 Bridge / Agent / WechatGroupChannel 链路。

---

## 文件职责

- `bridge/agent_bridge.py`：识别临时模型故障；从配置构造模型 fallback 候选；在 `call()` / `call_stream()` 中按候选顺序尝试。
- `channel/wechat_group/wechat_group_channel.py`：在微信群发送前隐藏底层模型错误；强制回复时发送脱敏兜底文案。
- `config.py`：新增最小配置键，默认关闭显式 fallback 候选，保留向后兼容。
- `config-template.json`：补充配置模板字段。
- `channel/web/web_channel.py`：在 `/api/models` 的 chat capability 中返回并保存 `model_fallbacks`。
- `channel/web/static/js/console.js`：在 Web 控制台“模型管理 -> 主模型”卡片中配置备用模型列表。
- `tests/test_agent_model_fallback.py`：覆盖模型 fallback 与临时错误分类。
- `tests/test_models_handler.py`：覆盖 `model_fallbacks` 的 Web API 返回与保存。
- `tests/test_models_console.py`：覆盖 Web 模型页存在备用模型配置入口。
- `tests/test_wechat_group_channel.py`：覆盖微信群错误不外显与强制回复兜底。
- `CHANGES.md`：记录本次代码变更与验证结果。

## 配置约定

新增配置：

```json
"model_fallbacks": []
```

每个候选项支持：

```json
{
  "bot_type": "custom:backup01",
  "model": "backup-model"
}
```

空列表表示不显式配置备用渠道。运行时仍会先使用当前 `bot_type/model`，再按 `model_fallbacks` 顺序尝试。候选缺少 `bot_type` 时按 `model` 自动推断；候选缺少 `model` 时使用当前模型或自定义 Provider 默认模型。

## 自审

- 覆盖需求：已覆盖错误不外显、模型 fallback、全部失败后的强制回复兜底。
- 范围控制：仅补 Web 控制台“模型管理 -> 主模型”备用模型配置入口，不引入新依赖，不改变微信群主链路。
- 风险点：流式请求只在第一个 chunk 即临时错误时切换，避免已经输出部分内容后切换导致上下文混乱。

## 实施结果

- 已完成 `bridge/agent_bridge.py`：`AgentLLMModel` 支持 `model_fallbacks`，流式和非流式调用均会在临时模型故障时尝试下一个候选；非临时 400 类错误不切换。
- 已完成 fallback 简写推断：`model_fallbacks` 候选仅填写模型名时，会按模型名前缀推断 Provider，不受全局 `bot_type` 干扰。
- 已完成 `channel/web/web_channel.py`：`/api/models` 的 chat capability 返回 `model_fallbacks`，保存主模型时可同步持久化备用模型候选。
- 已完成 `channel/web/static/js/console.js`：Web 控制台“模型管理 -> 主模型”卡片新增备用模型列表配置，可添加、移除、选择 Provider 或按模型名推断。
- 已完成 `channel/wechat_group/wechat_group_channel.py`：微信群发送层仅对 `AgentBridge` 包装出的临时模型错误做脱敏；`wechat_group_force_reply = true` 时发送 `别@我了哥，没Token了。`；普通工具、插件或业务错误即使包含 timeout 也仍正常回复。
- 已完成 `config.py` 与 `config-template.json`：新增 `model_fallbacks` 默认空列表。
- 已完成 `tests/test_agent_model_fallback.py` 与 `tests/test_wechat_group_channel.py`：覆盖本次核心行为。
- 已完成 `CHANGES.md`：记录本次改动和验证结果。
