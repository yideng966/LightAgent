## 源码部署

### 1. 克隆项目代码

```bash
git clone https://github.com/yideng966/LightAgent
cd LightAgent/
```

<Tip>
  若遇到网络问题可使用国内仓库地址：https://github.com/yideng966/LightAgent
</Tip>

### 2. 安装依赖

核心依赖（必选）：

```bash
pip3 install -r requirements.txt
```

扩展依赖（可选，建议安装）：

```bash
pip3 install -r requirements-optional.txt
```

如需接入个人微信群，源码部署还需要 Node.js，并在 sidecar 目录安装 npm 依赖：

```bash
cd channel/wechat_group/sidecar
npm install
cd ../../..
```

> 国内网络可使用镜像源加速：`pip3 install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`

### 3. 安装 LightAgent CLI

安装命令行工具，用于管理服务和技能：

```bash
pip3 install -e .
```

安装后即可使用 `lightagent` 命令：

```bash
lightagent help
```

<Note>
  此步骤为推荐操作。安装后可以使用 `lightagent start`、`lightagent stop`、`lightagent update` 等命令管理服务，也可以使用 `lightagent skill` 管理技能。如果不安装 CLI，可以使用 `./run.sh` 或 `python3 app.py` 运行。
</Note>

### 3.1 安装浏览器工具（可选）

如需使用浏览器工具（控制浏览器访问网页、填写表单等），运行：

```bash
lightagent install-browser
```

该命令会自动安装 Playwright 和 Chromium 浏览器。详细说明参考 [浏览器工具文档](/zh/tools/browser)。

<Note>
  浏览器工具依赖较重（~300MB），如不需要可跳过，不影响其他功能正常使用。
</Note>

### 4. 配置

复制配置文件模板并编辑：

```bash
cp config-template.json config.json
```

在 `config.json` 中填写模型 API Key 和通道类型等配置，详细说明参考各 [模型文档](/zh/models/minimax)。

### 5. 运行

**使用 LightAgent CLI 运行（推荐）：**

```bash
lightagent start
```

**或者本地前台运行：**

```bash
python3 app.py
```

运行后默认启动 Web 控制台，访问 `http://localhost:9899` 开始对话和管理Agent。

**服务器后台运行（不使用 CLI 时）：**

```bash
nohup python3 app.py & tail -f nohup.out
```

<Tip>
  **服务器公网访问 Web 控制台**：默认 `web_host` 仅监听 `127.0.0.1`（本机访问），需公网访问时请在 `config.json` 中将 `web_host` 设为 `0.0.0.0`，同时强烈建议设置 `web_password` 启用鉴权。此外还需在防火墙/安全组中放行 `9899` 端口，建议仅对指定 IP 开放以保证安全。
</Tip>

## Docker 部署

使用 Docker 部署无需下载源码和安装 Python、Node.js 或 npm 依赖。镜像已包含 `/usr/local/bin/node`、个人微信群 Wechaty sidecar 和锁定后的生产依赖。Agent 模式下如需直接访问更多宿主机能力，仍可选择源码部署。

<Note>
  需要安装 [Docker](https://docs.docker.com/engine/install/) 和 docker-compose。
</Note>

**1. 下载 Compose 与环境变量模板**

```bash
curl -O https://raw.githubusercontent.com/yideng966/LightAgent/master/docker/docker-compose.yml
curl -O https://raw.githubusercontent.com/yideng966/LightAgent/master/docker/.env.example
cp .env.example .env
```

编辑 `.env`，把示例值替换为强随机密码。`WEB_PASSWORD` 为必填项，不能把真实密码提交到 Git。

**2. 启动容器**

```bash
sudo docker compose up -d
```

首次启动后访问 `http://localhost:9899`，在 Web 控制台配置模型，然后进入“通道管理 -> 接入通道 -> 个人微信群”扫码。Docker 用户无需在宿主机执行 sidecar 的 `npm install`。

**3. 查看日志**

```bash
sudo docker logs -f lightagent
```

Compose 使用两个相对于 `docker-compose.yml` 的持久化目录：

- `./config` 挂载到 `/home/agent/.lightagent`，保存 `config.json`、密钥、日志、插件配置与用户安装插件、微信登录态、媒体和群数据库；它不只是单一配置文件目录，必须整体备份。
- `./data` 挂载到 `/home/agent/lightagent`，保存 Agent workspace、记忆、知识库、技能、MCP 和 scheduler。
- `/app` 是随镜像升级的应用目录，包含项目代码、Playwright 和 sidecar `node_modules`，不要给它添加 volume。

Compose 已让 Web 服务监听 `0.0.0.0` 并强制启用密码。若需要公网访问，还应在防火墙或安全组中限制 `9899` 的来源 IP。重启或重建容器不会覆盖 `./config` 和 `./data`。

## 核心配置项

<Tabs>
  <Tab title="源码部署（config.json）">
    ```json
    {
      "channel_type": "web",
      "model": "deepseek-v4-flash",
      "deepseek_api_key": "",
      "agent": true,
      "agent_workspace": "~/lightagent",
      "agent_max_context_tokens": 40000,
      "agent_max_context_turns": 30,
      "agent_max_steps": 15,
      "lightagent_lang": "auto"
    }
    ```
  </Tab>
  <Tab title="Docker 部署（docker-compose.yml）">
    ```yaml
    environment:
      LIGHTAGENT_DATA_DIR: /home/agent/.lightagent
      WEB_HOST: "0.0.0.0"
      WEB_PASSWORD: "${WEB_PASSWORD:?Set WEB_PASSWORD in docker/.env before starting LightAgent}"
    volumes:
      - ./config:/home/agent/.lightagent
      - ./data:/home/agent/lightagent
    ```
  </Tab>
</Tabs>

| 参数 | 环境变量 | 说明 | 默认值 |
| --- | --- | --- | --- |
| `channel_type` | `CHANNEL_TYPE` | 接入渠道类型 | `web` |
| `model` | `MODEL` | 模型名称 | `deepseek-v4-flash` |
| `agent` | `AGENT` | 是否启用 Agent 模式 | `true` |
| `agent_workspace` | - | Agent 工作空间路径 | `~/lightagent` |
| `agent_max_context_tokens` | `AGENT_MAX_CONTEXT_TOKENS` | 最大上下文 tokens | `40000` |
| `agent_max_context_turns` | `AGENT_MAX_CONTEXT_TURNS` | 最大上下文记忆轮次 | `30` |
| `agent_max_steps` | `AGENT_MAX_STEPS` | 单次任务最大决策步数 | `15` |
| `lightagent_lang` | `LIGHTAGENT_LANG` | 界面、命令文案、系统提示词等的语言，`auto` 自动检测，可设为 `zh` / `en` | `auto` |

<Tip>
  全部配置项可在项目 [`config.py`](https://github.com/yideng966/LightAgent/blob/master/config.py) 文件中查看。Docker 部署建议通过 Web 控制台管理模型和通道，保存结果位于 `./config/config.json`；不要在 Compose 中注入空 API Key 或模型环境变量，否则会覆盖已保存配置。
</Tip>
