## 概览

个人微信群通道可以为已选择且稳定身份已确认的群生成日报、周报、月报或自定义时间范围报告。每份报告固定包含发言统计、排行榜、重点话题、精彩发言和群聊链接；数据只从当前群的归档消息中读取。

报告功能默认关闭。启用后，归档会持续保留在部署数据目录中，请由部署管理员负责磁盘空间、隐私告知和备份策略。

## 默认回复风格

新建工作区的默认 `AGENT.md` 和微信群内置人设不再要求使用 emoji 或 `[破涕为笑]`、`[吃瓜]` 等微信文字表情。这里的微信文字表情属于回复正文，不等同于作为独立媒体发送的表情包。

本次调整不改变表情包的自动收集、主动回复频率、检索或发送能力。升级也不会覆盖已有工作区的 `AGENT.md`、现有 `config.json` 或管理员保存的自定义人设。

## 启用方式

1. 在 Web 控制台打开“通道 -> 个人微信群 -> 群聊报告”。
2. 选择已确认的目标群，开启“启用当前群报告”。
3. 保存设置后，可按需启用日报、周报或月报，并设置 `Asia/Shanghai` 等 IANA 时区和发送时间。
4. 使用“生成预览”检查当前周期的数据、文字或长图；确认后点击“立即发送”。

未选择群、未确认稳定群身份或未登录 Web 控制台时，报告接口不会返回群数据或本地文件路径。

## 输出形式

| 形式 | 行为 |
| --- | --- |
| 纯文本 | 只发送基于六模块结构的文字报告。 |
| 图片 | 只发送 941px 宽的报告长图；浏览器或图片发送失败时显示失败状态，不发送文字。 |
| 图片优先，失败转纯文本 | 优先发送长图；在图片渲染或平台明确拒绝且尚未成功发送图片时，发送同一份文字模板作为兜底。 |

若图片发送结果超时而无法确定是否已经送达，系统标记为“发送结果未知”，不会自动补发全文。多张长图已有任一分片成功后，失败重试只会发送未完成分片。

## 权限与隔离

- 报告统计、快照、预览资源、投递记录、定时任务和日报记忆均按 `stable_room_id` 隔离；旧 runtime 群 ID 仅在已确认的历史别名范围内兼容读取。
- 群内手动生成默认只允许当前群管理员。Web 管理员可以配置、预览和发送，但不能指定其他群 ID。
- 普通群成员不能借助 Agent 工具创建报告、修改报告设置或写入日报记忆。
- “群聊 -> 群与管理员 -> 管理员门禁能力”提供独立的“新增/修改/删除技能”开关。开启后，只有当前 `stable_room_id + stable_member_id` 对应的群管理员可以安装、创建、更新、回滚、编辑、启停或卸载技能；列表、搜索、详情、更新检查和校验仍可只读使用。
- 普通群成员触发管理员门禁能力时，请求会在通道层静默拒绝，不会向群内发送权限提示；身份未确认、报告未启用等其他业务错误仍会正常反馈。
- 报告链接抓取始终使用严格 SSRF 校验，并逐跳检查重定向目标；被拒绝、超时、需要登录或正文为空的链接会保留明确状态，不会由模型猜测网页内容。

## 模板与图片

默认图片模板来自内置 Skill `wechat-group-report-cyber-intelligence`，使用赛博智能样式并随镜像发布。图片产物保存在 `agent_workspace/images/wechat_group_reports`；Docker 默认对应 `/home/agent/lightagent/images/wechat_group_reports`，不会写入镜像内的 `/app`。

自定义文字模板仅支持控制台列出的简单字段，不支持属性访问、循环、函数或表达式。保存前会校验必填模块、花括号和 64 KiB 大小限制。

## 真实验收

部署后请在真实微信群中验证：

1. 在目标群由管理员触发日报、周报、月报和自定义范围报告。
2. 修改一位成员的群昵称后，确认统计仍合并到同一成员。
3. 检查图片、图片优先回退、长链接、多图分片和断线/未知发送状态。
4. 确认报告只发送到当前稳定群，且回复和图片不会泄露宿主机路径、稳定 ID 或运行时 ID。
