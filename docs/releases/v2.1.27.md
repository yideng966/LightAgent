> LightAgent - 多渠道 Agent Harness 与可长期运行的 AI 助手框架

本版本修复个人微信群在工具完成后的回复回归。贴纸搜索、贴纸发送等工具结束后，模型返回普通纯文本最终答复时不会再被误判为候选故障，也不会向群内暴露 422 技术错误。

## Bug 修复

- 修复工具执行完成后，模型未调用内部完成工具便返回纯文本时被连续切换候选、最终无法返回结果的问题；系统现在会保留当前健康候选链并重新请求一次最终答复，首段临时文本不会进入群消息或会话历史。
- 修复微信群可能直接发送 `Agent error`、状态码及内部协议错误的问题；明确触发的请求会收到简短可读提示，自由回复场景则保持静默。

## 安装

**Docker Hub：**

```bash
docker pull yideng966/lightagent:v2.1.27
```

**GitHub Container Registry：**

```bash
docker pull ghcr.io/yideng966/lightagent:v2.1.27
```

**完整技能镜像：**

```bash
docker pull yideng966/lightagent:v2.1.27-skills-full
docker pull ghcr.io/yideng966/lightagent:v2.1.27-skills-full
```
