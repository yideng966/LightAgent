> LightAgent - 多渠道 Agent Harness 与可长期运行的 AI 助手框架

本版本将 GitHub 提交通知扩展为可配置的仓库事件通知。管理员可在 Web 控制台精确选择进入微信群的事件和 action，同时继续沿用安全验签、稳定群投递和默认 `push + main` 行为。

## 新增功能

- 支持 GitHub 当前 53 个仓库级 Webhook 事件，可选择“选定事件”或“全部事件”，并为 Pull Request、Issue、workflow、release 等事件配置 action 过滤。
- 在「群聊 -> 基础设置」新增事件配置弹窗，支持搜索、分类、常用事件、全选、清空和逐 action 勾选，桌面端与移动端均可完成配置。
- 全部事件模式可接收 GitHub 后续新增的未知仓库事件，并生成只包含仓库、事件、action、操作者和 GitHub 链接的最小摘要。

## 优化改进

- 默认配置仍只通知 `main` 分支的 `push`，原提交聚合文本、Webhook 地址和配置字段保持兼容，升级后不会自动扩大群通知范围。
- 所有事件继续使用 HMAC-SHA256 验签、delivery 去重、stable room 和 scheduler 重试链路；`ping` 只检查连通性，不发送群消息。
- 通知只读取受控白名单字段，不保存或转发原始 payload、评论正文、嵌套对象、Secret scanning 内容或私有安全公告摘要；配置 API 继续隐藏真实 Secret，并保持环境变量优先。

## 安装

**Docker Hub：**

```bash
docker pull yideng966/lightagent:v2.1.15
```

**GitHub Container Registry：**

```bash
docker pull ghcr.io/yideng966/lightagent:v2.1.15
```

**完整技能镜像：**

```bash
docker pull yideng966/lightagent:v2.1.15-skills-full
```
