> LightAgent - 多渠道 Agent Harness 与可长期运行的 AI 助手框架

本版本延续 v2.1.8 的微信群记忆与知识隔离改进，重点修复 Windows 安装包未生成却被发布流程误判为成功的问题。v2.1.9 会严格校验每个平台的安装产物，桌面用户请使用本版本 Assets。

## 优化改进

- 桌面依赖下载增加有限网络重试，降低 npm Registry 瞬时断连导致单个平台构建失败的概率，同时保留明确的重试次数与等待上限。
- 桌面源码编译和 electron-builder 安装包打包改为独立步骤，使各平台的执行阶段与失败位置更清晰。
- 每个平台上传安装包时都要求至少存在一个匹配产物，Windows `.exe` 或 macOS `.dmg` 缺失会直接阻断 GitHub Release，不再发布不完整资产集合。

## Bug 修复

- 修复 Windows Runner 在完成桌面源码编译后没有继续执行 electron-builder，导致 NSIS 安装包实际未生成的问题。
- 修复 Windows 没有生成任何安装文件时，Actions artifact 上传仍被忽略并把矩阵标记为成功的问题。

## 安装

**Docker Hub：**

```bash
docker pull yideng966/lightagent:v2.1.9
```

**GitHub Container Registry：**

```bash
docker pull ghcr.io/yideng966/lightagent:v2.1.9
```

**完整技能镜像：**

```bash
docker pull yideng966/lightagent:v2.1.9-skills-full
```

**桌面端：**

从本 Release 的 Assets 下载适用于当前平台的 `.exe` 或 `.dmg` 安装包。
