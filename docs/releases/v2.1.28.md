> LightAgent - 多渠道 Agent Harness 与可长期运行的 AI 助手框架

本版本修复个人微信群图片理解回复可能暴露内部答复规划，以及回复中出现微信内部成员编码的问题。升级后无需手动修改旧视觉提示词，图片回复会保持客观，无法解析的 mention 也不会再泄露内部标识。

## Bug 修复

- 修复群友发送图片后，视觉摘要或文本模型可能把“用户可能想让我”“我可能会这样回应”等内部规划发送到群里的问题；旧默认视觉提示词会在运行时自动替换，自定义关注点会追加客观描述边界，携带图片上下文的群回复请求会按请求关闭模型思考。
- 修复微信群回复开头可能暴露长十六进制成员编码或 `wxid_` 内部 ID 的问题；发送、归档和后续上下文会统一清理不可读标识，联系人无法安全解析时不再生成原生 mention。

## 安装

**Docker Hub：**

```bash
docker pull yideng966/lightagent:v2.1.28
```

**GitHub Container Registry：**

```bash
docker pull ghcr.io/yideng966/lightagent:v2.1.28
```

**完整技能镜像：**

```bash
docker pull yideng966/lightagent:v2.1.28-skills-full
docker pull ghcr.io/yideng966/lightagent:v2.1.28-skills-full
```
