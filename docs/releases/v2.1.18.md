> LightAgent - 多渠道 Agent Harness 与可长期运行的 AI 助手框架

本版本修复微信群长期记忆和群友画像管理体验：群永久记忆的自然语言内容现在稳定输出为简体中文；群友画像自主学习页面在展开、配置、执行和回滚过程中保持布局与状态稳定。

## 优化改进

- 群永久记忆的摘要、记忆正文和 Dream 审计摘要统一使用简体中文；即使原始群消息或已有记忆包含其他语言，也只保留必要的专有名词、产品名、代码和 URL，结构修复重试继续遵循相同语言约束。
- 群友画像自主学习改为展开时按需加载，并提供明确的加载、保存、执行、差异查看、回滚和无新消息状态；未保存的策略会被保留并阻止直接执行，避免实际运行继续使用旧配置。

## Bug 修复

- 修复 Web 控制台「群聊 -> 群友画像 -> 自主学习」展开后画像列表被压缩、内容重叠和移动端界面错位的问题；桌面双栏与移动端单列现在统一使用主内容区滚动，不再产生横向溢出。
- 修复查看差异或异步刷新后自主学习面板关闭、配置输入丢失、执行与回滚重复刷新，以及学习完成后画像仍显示旧数据的问题；快速切换群或搜索时，旧请求也不会再覆盖当前群画像。

## 安装

**Docker Hub：**

```bash
docker pull yideng966/lightagent:v2.1.18
```

**GitHub Container Registry：**

```bash
docker pull ghcr.io/yideng966/lightagent:v2.1.18
```

**完整技能镜像：**

```bash
docker pull yideng966/lightagent:v2.1.18-skills-full
```
