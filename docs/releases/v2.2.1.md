> LightAgent - 多渠道 Agent Harness 与可长期运行的 AI 助手框架

本版本聚焦个人微信群通道的稳定性，修复表情包误入图片理解、自由回复识图失败仍发言以及内部静默判断外泄，并降低 Wechat4u 联系人同步重复告警对日志的干扰。

## 优化改进

- Wechat4u 联系人同步持续返回 `1205` 时，同类告警会按时间窗口合并并输出计数摘要；其他 sidecar 错误以及原有联系人重试、登录和消息收发行为保持不变。

## Bug 修复

- 微信群现在会独立区分图片和表情包；表情包仍可按配置归档和收集，但不会再被当作普通图片触发 Vision、当前图片理解或图片自由回复。
- 自由回复处理当前图片或最近图片时，如果视觉服务异常、返回失败或没有可用摘要，将保持静默且不占用回复冷却；明确 `@` 或引用机器人的图片请求保持原有行为。
- 模型输出“无需回复”“不插嘴”等括号内部静默判断时，不再把该说明发送到群里；普通未包裹文本和正常解释回复不受影响。

## 安装

**Docker Hub：**

```bash
docker pull yideng966/lightagent:v2.2.1
```

**GitHub Container Registry：**

```bash
docker pull ghcr.io/yideng966/lightagent:v2.2.1
```

**完整技能镜像：**

```bash
docker pull yideng966/lightagent:v2.2.1-skills-full
docker pull ghcr.io/yideng966/lightagent:v2.2.1-skills-full
```
