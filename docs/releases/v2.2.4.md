> LightAgent - 多渠道 Agent Harness 与可长期运行的 AI 助手框架

本版本完善 GitHub Release 到微信群的通知内容。发布事件现在会直接展示版本摘要与变更详情，同时过滤安装命令和文档链接等尾部内容，减少群内冗余信息。

## 优化改进

- GitHub Release Webhook 群通知会在版本标题和详情链接后追加发行摘要，将 Markdown 标题与无序列表转换为易读的纯文本，并保留必要换行。
- 通知会跳过匹配当前仓库名的项目定位引用，并在 Markdown 分隔线处停止；正文仍受群消息长度限制，PR、Issue、讨论和评论等其他事件的正文安全边界保持不变。

---

## 安装

**Docker Hub：**

```bash
docker pull yideng966/lightagent:v2.2.4
```

**GitHub Container Registry：**

```bash
docker pull ghcr.io/yideng966/lightagent:v2.2.4
```

**完整技能镜像：**

```bash
docker pull yideng966/lightagent:v2.2.4-skills-full
docker pull ghcr.io/yideng966/lightagent:v2.2.4-skills-full
```
