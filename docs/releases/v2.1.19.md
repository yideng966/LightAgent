> LightAgent - 多渠道 Agent Harness 与可长期运行的 AI 助手框架

本版本修复 IM 渠道可能把模型思考过程作为普通回复发送的问题。微信群等渠道现在只会收到最终正文，Web 控制台原有的思考展示行为保持不变。

## Bug 修复

- 修复部分模型或兼容代理将 `think` 思考块写入流式正文，且标签跨分片返回时，思考内容、未闭合内容或残余结束标签可能进入用户回复和会话历史的问题；IM 渠道现在会完整过滤思考块，标准 `reasoning_content` 继续与最终正文隔离。

---

## 安装

**Docker Hub：**

```bash
docker pull yideng966/lightagent:v2.1.19
```

**GitHub Container Registry：**

```bash
docker pull ghcr.io/yideng966/lightagent:v2.1.19
```

**完整技能镜像：**

```bash
docker pull yideng966/lightagent:v2.1.19-skills-full
```
