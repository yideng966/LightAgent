> LightAgent - 多渠道 Agent Harness 与可长期运行的 AI 助手框架

本版本集中修复个人微信群回复的可靠性与隐私边界。生图请求不再被增强上下文误判为群聊报告，模型的内部分析、协议标签和临时路径也不会再作为群消息发送或进入后续上下文。

## Bug 修复

- 修复 `@机器人 画一张图` 已进入生图流程后，仍被群聊摘要或近期消息中的“报告”“发送”等词误判为群聊报告的问题；生图现在始终使用当前用户的原始提示词完成意图判断。

## 安全修复

- 微信群最终正文增加严格交付边界。模型返回裸分析、思考标签、空工具标签、损坏的发送协议或内部临时路径时，当前候选会被整体丢弃并切换备用模型，不再把标签前后的片段猜测为可发送回复。
- 阻止修复前已发送的机器人异常正文通过近期群聊、滚动摘要和旧会话继续回灌模型，避免相同内部口吻在后续回复中反复出现。
- 自定义 OpenAI 兼容端点会实际携带禁用思考参数；端点明确拒绝该参数时直接切换候选，不会移除保护后继续请求。

## 安装

**Docker Hub：**

```bash
docker pull yideng966/lightagent:v2.1.25
```

**GitHub Container Registry：**

```bash
docker pull ghcr.io/yideng966/lightagent:v2.1.25
```

**完整技能镜像：**

```bash
docker pull yideng966/lightagent:v2.1.25-skills-full
docker pull ghcr.io/yideng966/lightagent:v2.1.25-skills-full
```
