> LightAgent - 多渠道 Agent Harness 与可长期运行的 AI 助手框架

本版本修复部分自定义 OpenAI 兼容端点无法处理微信群图片请求的问题。升级后，相关端点会收到其支持的低推理等级，同时继续保持图片回复的禁用思考控制。

## Bug 修复

- 修复自定义 OpenAI 兼容端点仅接受 `low`、`medium`、`high` 时，因收到 `reasoning_effort=none` 而返回 HTTP 422 的问题；微信群当前图片、已匹配图片上下文及自由回复 Scorer 请求会在出站时使用 `low`，并继续携带 `thinking={"type":"disabled"}`，原生 OpenAI 和其他 Provider 行为不变。

## 安装

**Docker Hub：**

```bash
docker pull yideng966/lightagent:v2.1.30
```

**GitHub Container Registry：**

```bash
docker pull ghcr.io/yideng966/lightagent:v2.1.30
```

**完整技能镜像：**

```bash
docker pull yideng966/lightagent:v2.1.30-skills-full
docker pull ghcr.io/yideng966/lightagent:v2.1.30-skills-full
```
