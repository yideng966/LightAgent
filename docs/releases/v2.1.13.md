> LightAgent - 多渠道 Agent Harness 与可长期运行的 AI 助手框架

本版本完善个人微信群的成员事件通知，并优化 Docker 多架构镜像发布路径。管理员现在可以为已选微信群配置入群欢迎和离群通知；镜像发布继续提供 AMD64、ARM64、基础版和完整技能版，同时降低 ARM64 构建的等待与失败风险。

## 新增功能

- 新增微信群入群欢迎与离群通知：支持全局默认和按稳定群设置“跟随全局 / 自定义 / 关闭”，可分别配置文本或本地图片。
- 入群文本通知会真实 mention 新成员；离群通知使用可读成员名称，避免对已离群成员发起无效 mention。
- 新增“群聊 -> 进退群消息”管理界面，提供白名单变量、独立草稿、实时预览和图片上传；图片会安全保存到持久化工作区。

## 优化改进

- Docker 镜像改为在原生 AMD64 与 ARM64 Runner 上分别构建并合并多架构镜像，避免 QEMU 模拟带来的 ARM64 构建缓慢和偶发失败。
- 为基础版和完整技能版启用隔离构建缓存，并重排 Docker 依赖层；普通源码更新可复用系统、Python 和 Chromium 依赖，同时保留微信群图片报告所需的 Chromium 能力。

## 安装

**Docker Hub：**

```bash
docker pull yideng966/lightagent:v2.1.13
```

**GitHub Container Registry：**

```bash
docker pull ghcr.io/yideng966/lightagent:v2.1.13
```

**完整技能镜像：**

```bash
docker pull yideng966/lightagent:v2.1.13-skills-full
```
