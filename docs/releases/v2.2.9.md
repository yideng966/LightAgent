> LightAgent - 多渠道 Agent Harness 与可长期运行的 AI 助手框架

本版本修复微信群图片理解中 Vision 模型无效摘要的误判问题，同时补齐一键安装脚本对微信群 Sidecar 依赖的自动处理。

## Bug 修复

- 修复 Vision 模型（agnes-2.0-flash）返回"我无法查看这张图片""图片加载失败"等自述失败的摘要时，被 `_is_successful_image_summary()` 误判为可用摘要，注入 LLM 后被复述成"图片我这边没加载出来 看不到内容 你重新发一张"的问题。现在无效摘要（含 25 个中英文失败标记 + 空泛主语正则匹配）会被正确标记为 `summary_generated=False`，自由回复链路静默处理。
- 强化 `_should_suppress_free_reply_for_image_failure()` 的 current_image 分支：同时检查诊断完整性、图片消息 ID、命中原因与摘要可用性，任一条件不满足即静默，防止诊断缺失时仍进入 Agent。

## 优化改进

- 一键安装脚本（Linux/macOS/Windows）在选择个人微信群时自动检查 Node.js 18+、npm 和 sidecar 锁文件，使用 `npm ci --omit=dev` 安装并验证生产依赖。
- sidecar 安装或模块验证失败时停止生成微信群配置和启动服务，避免将不可用部署报告为成功。

## 安装

**Docker Hub：**

```bash
docker pull yideng966/lightagent:v2.2.9
```

**GitHub Container Registry：**

```bash
docker pull ghcr.io/yideng966/lightagent:v2.2.9
```

**完整技能镜像：**

```bash
docker pull yideng966/lightagent:v2.2.9-skills-full
docker pull ghcr.io/yideng966/lightagent:v2.2.9-skills-full
```
