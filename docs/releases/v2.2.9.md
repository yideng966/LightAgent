> LightAgent - 多渠道 Agent Harness 与可长期运行的 AI 助手框架

修复了群里发图片后机器人偶尔回复"图片没加载出来，重新发一张"的尴尬问题，同时让一键安装脚本能自动检查微信群所需的运行环境，缺依赖时给出明确提示，不再安装到一半才报错。

## Bug 修复

- 修复部分图片发给机器人后，机器人回复"图片我这边没加载出来 看不到内容"的问题。原因是图片识别服务有时会返回"我无法查看这张图片"而非真实描述，旧逻辑误以为识别成功，导致模型把这条无效描述复述出来。现在识别失败时会自动静默，不再发出错误提示。
- 修复图片识别诊断信息不完整时，少数情况下仍会进入对话链路的问题。

## 优化改进

- 一键安装脚本现在自动检查微信群所需的 Node.js 环境和依赖包，缺少时给出明确提示，不会安装到一半才失败。
- 依赖安装或校验失败时，安装脚本会停止生成微信群配置，不再把不可用环境报告为安装成功。

## 安装

**Docker Hub：**

```bash
docker pull yideng966/lightagent:v2.2.9
```

**GitHub Container Registry：**

```bash
docker pull ghcr.io/yideng966/lightagent:v2.2.9
```

**完整技能镜像：**

```bash
docker pull yideng966/lightagent:v2.2.9-skills-full
docker pull ghcr.io/yideng966/lightagent:v2.2.9-skills-full
```
