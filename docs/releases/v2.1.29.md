> LightAgent - 多渠道 Agent Harness 与可长期运行的 AI 助手框架

本版本集中收敛个人微信群的自由回复行为：表情包会先转换为安全语义并交由既有规则判断是否接话，Agent 技术错误不再暴露到群内。同时移除情绪与主动性模块，并提高回复生成期间对群内新消息的容忍度。

## 优化改进

- 观察式自由回复生成期间，默认允许同群新增 5 条入站消息，不再因少量新消息立即丢弃候选；管理员可在 Web 控制台将容忍数量调整为 0–100，期间出现新的机器人回复时旧候选仍会立即抑制。

## Bug 修复

- 修复普通未 @ 表情包会触发机器人直接解读和回复的问题；启用自由回复图片理解后，表情包只会先转换为不含微信协议字段、URL 或本机路径的短语义并进入群聊上下文，最终是否接话继续由现有自由回复规则、Scorer 和 Judge 决定。
- 修复 Provider 参数、反序列化或其他 `Agent error:` 技术细节被发送到微信群的问题；明确触发请求只返回简短提示，自由回复等 ambient 请求静默结束，限流提示和管理员权限等业务错误保持原行为。

## 破坏性变更

- 删除微信群情绪与主动性功能。曾配置群情绪状态、自由回复时段规则或打字延迟的用户会受到影响：升级后相关后台逻辑、Web 控制台入口和配置项不再生效，历史情绪数据库文件会保留但不再读取。无需迁移数据，可从 `config.json` 删除 `wechat_group_emotion_*`、`wechat_group_free_reply_time_rules*` 和 `wechat_group_free_reply_typing_*` 旧配置；接话频率继续通过“群聊 -> 自由回复”的活动档位和现有判断规则管理。

## 安装

**Docker Hub：**

```bash
docker pull yideng966/lightagent:v2.1.29
```

**GitHub Container Registry：**

```bash
docker pull ghcr.io/yideng966/lightagent:v2.1.29
```

**完整技能镜像：**

```bash
docker pull yideng966/lightagent:v2.1.29-skills-full
docker pull ghcr.io/yideng966/lightagent:v2.1.29-skills-full
```
