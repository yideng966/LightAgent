> LightAgent - 多渠道 Agent Harness 与可长期运行的 AI 助手框架

本版本修复 Docker 浮动标签的镜像变体覆盖问题。升级后 `latest` 稳定指向基础镜像，完整技能镜像继续由独立的 `skills-full` 标签提供。

## Bug 修复

- 关闭标签发布时自动生成的隐式 `latest`，避免后完成的完整技能镜像覆盖基础镜像；`latest`、`skills-full` 及其版本化标签现在分别对应正确变体。

---

## 安装

**Docker Hub：**

```bash
docker pull yideng966/lightagent:v2.1.12
```

**GitHub Container Registry：**

```bash
docker pull ghcr.io/yideng966/lightagent:v2.1.12
```

**完整技能镜像：**

```bash
docker pull yideng966/lightagent:v2.1.12-skills-full
```
