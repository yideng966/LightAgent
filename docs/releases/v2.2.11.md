> LightAgent - 多渠道 Agent Harness 与可长期运行的 AI 助手框架

本版本修复了容器升级后内置生图能力可能无法读取正确配置的问题，并统一保护内置技能名称。升级遗留文件无需手工清理，其他已安装技能的运行和管理方式保持不变。

## Bug 修复

- 修复容器升级后生图能力误用历史副本，导致配置加载失败、无法生成图片的问题。
- 内置技能现在始终使用随当前版本发布的实现；升级遗留的同名副本会被忽略但不会自动删除。
- 在线安装、本地导入和对话创建技能时会提前拒绝与内置技能重名的内容，避免显示安装成功但实际无法使用；其他非同名技能不受影响。

## 安装

**Docker Hub：**

```bash
docker pull yideng966/lightagent:v2.2.11
```

**GitHub Container Registry：**

```bash
docker pull ghcr.io/yideng966/lightagent:v2.2.11
```

**完整技能镜像：**

```bash
docker pull yideng966/lightagent:v2.2.11-skills-full
docker pull ghcr.io/yideng966/lightagent:v2.2.11-skills-full
```
