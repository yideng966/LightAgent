> LightAgent - 多渠道 Agent Harness 与可长期运行的 AI 助手框架

本版本为个人微信群增加独立的技能管理管理员门禁。管理员现在可以在 Web 控制台明确控制普通群成员是否能够新增、修改或删除技能，同时保留技能查询类只读操作。

## 新增功能

- “群聊 -> 群与管理员 -> 管理员门禁能力”新增默认开启的“新增/修改/删除技能”开关，覆盖安装、创建、更新、回滚、编辑、启用、禁用和卸载技能；技能列表、搜索、详情、更新检查和校验仍可只读使用。

## 安全修复

- 聊天中的 `/skill` 变更命令统一按当前 `stable_room_id + stable_member_id` 管理员身份校验，普通成员命中门禁时静默处理，不向群内发送权限提示。
- Agent 使用 `write`、`edit` 或 `bash` 修改 workspace 技能目录前会再次执行权限复核，避免在通用工作区写入门禁关闭时绕过技能管理限制。

## 安装

**Docker Hub：**

```bash
docker pull yideng966/lightagent:v2.2.6
```

**GitHub Container Registry：**

```bash
docker pull ghcr.io/yideng966/lightagent:v2.2.6
```

**完整技能镜像：**

```bash
docker pull yideng966/lightagent:v2.2.6-skills-full
docker pull ghcr.io/yideng966/lightagent:v2.2.6-skills-full
```
