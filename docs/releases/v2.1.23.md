> LightAgent - 多渠道 Agent Harness 与可长期运行的 AI 助手框架

本版本将个人微信群统一升级为 V2 上下文引擎。机器人现在会在每轮请求中读取同一群所有成员形成的有界近期现场和 24 小时滚动摘要，同时继续隔离每位成员的短期对话线程，减少“只记得提问者、没看见其他群友刚说过什么”的上下文缺口。

## 新增功能

- 群级上下文覆盖当前稳定群内所有成员的安全消息，并按请求深度组合近期原文、24 小时滚动摘要和相关历史证据；同一来源会在摘要、原文、归档证据和成员线程之间去重。
- 新增可选的 Provider 会话续接合同和发送确认存储。只有明确支持安全分支与失效回放的 Provider 才能接入，锚点按群、成员、线程、模型和接口严格隔离，并在微信确认发送成功后才生效。

## 优化改进

- 24 小时摘要改为有界窗口重建，自动淘汰过期事实并保留最新原文；摘要暂不可用时仍使用近期群聊继续回答，不阻塞正常消息。
- Web 控制台“群聊 → 拟人化”改为平铺的单一页面滚动，只展示真实生效的会话作用域、线程有效期、摘要、归档证据、工具续接和回复长度设置。
- 当前 OpenAI-compatible Chat Completions 仍按每轮完整本地历史请求，不提交 `conversation_id` 或 `previous_response_id`；尚未支持 Provider 续接时，控制台不会展示无效开关。

## Bug 修复

- 修复普通请求主要围绕当前发言人取上下文、容易遗漏同群其他成员近期发言的问题；群级现场现在按稳定群汇集，成员 ID 只用于权限、画像和私有线程。
- 修复滚动摘要可能长期合并旧事实、并与近期原文或归档证据重复的问题；摘要现在带来源事件和 freshness 边界。
- 修复上下文构建异常时可能回到旧拼装逻辑的问题；异常路径现在仍保留 V2 权限约束、当前原文和同群最小安全现场。

## 破坏性变更

- `wechat_group_context_engine_mode` 和 Legacy 引擎已移除。升级后所有个人微信群统一使用 V2，旧配置中的 `legacy` 或 `v2` 值都会被忽略；仍需旧行为的部署应暂缓升级或回退到 `v2.1.22`。
- 完整上下文注入预览及其公开 API 已删除；自动化脚本不应再调用 `/api/wechat-group/memories/preview`。
- 已删除旧的最近上下文、本地摘要、回复策略和固定安全开关。请保留或迁移到 `wechat_group_session_scope`、`wechat_group_thread_followup_ttl_minutes`、`wechat_group_rolling_summary_enabled`、`wechat_group_tool_continuation_enabled`、`wechat_group_archive_evidence_enabled`、`wechat_group_archive_evidence_days` 与 `wechat_group_response_cleanup_max_chars`；旧 `wechat_group_continuation_enabled` 会在加载时一次性映射为工具续接开关。

## 安装

**Docker Hub：**

```bash
docker pull yideng966/lightagent:v2.1.23
```

**GitHub Container Registry：**

```bash
docker pull ghcr.io/yideng966/lightagent:v2.1.23
```

**完整技能镜像：**

```bash
docker pull yideng966/lightagent:v2.1.23-skills-full
docker pull ghcr.io/yideng966/lightagent:v2.1.23-skills-full
```
