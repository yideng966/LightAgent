> LightAgent - 多渠道 Agent Harness 与可长期运行的 AI 助手框架

本版本集中修复个人微信群自由回复的上下文污染与会话串扰问题，降低机器人误接群友对话、引用旧话题以及把内部上下文带入后续回复的概率。

## 优化改进

- 普通自由回复改为只参考当前群最近 30 分钟内最多 12 条安全消息，不再自动注入远期归档、旧摘要或旧焦点，减少无关历史干扰。
- 新增独立提问、连续交互和观察式自由回复三种会话历史模式，让机器人按触发场景选择上下文边界。
- 自由回复判定统一使用脱敏后的近场对话关系，保留必要的接话线索，同时不向判定模型暴露内部成员 ID、传输 XML 或本地路径。

## Bug 修复

- 修复“另一名群友刚发言，当前成员紧接短问句”时机器人可能误判为在询问自己的问题；明确面向全群或机器人的提问仍可正常触发。
- 修复本地摘要可能混入 WPS/app 传输 XML、base64、文件路径、敏感键值和 URL 查询参数的问题。
- 修复自由回复候选进入队列后已有其他群友接话，机器人仍继续回复的问题。
- 修复观察式自由回复在成功、异常、取消、文件回复或并发执行后可能污染原 Agent 会话历史的问题。
- 修复自主进化记录可能吸收回复增强块、思考过程或工具原文，并进一步影响后续群聊回复的问题。

## 安装

**Docker Hub：**

```bash
docker pull yideng966/lightagent:v2.1.6
```

**GitHub Container Registry：**

```bash
docker pull ghcr.io/yideng966/lightagent:v2.1.6
```

**完整技能镜像：**

```bash
docker pull yideng966/lightagent:v2.1.6-skills-full
```
