> LightAgent - 多渠道 Agent Harness 与可长期运行的 AI 助手框架

本版本修复微信群成员事件与群记忆文本路由的两个稳定性问题。扫码入群时即使暂时无法解析成员 ID，也能发送安全降级欢迎；群记忆任务遇到成功但正文为空的模型响应时，会自动尝试备用模型并保留可诊断的失败状态。

## Bug 修复

- 修复 wechat4u 已识别扫码入群、但成员或邀请人 ID 查找失败时欢迎事件被丢弃的问题。已选择且身份确认的群现在会继续发送当前配置的欢迎内容，成员名称回退为“新成员”、人数按 1 处理且不执行 mention；离群成员未知时仍不发送通知，避免误报。
- 修复群记忆提炼遇到模型返回空正文时不会尝试备用模型的问题。共享文本路由现在会按既有主备顺序继续请求可用模型，半开探测不会因空响应卡住；所有候选均不可用时保留失败状态且不推进群记忆游标，安全拒绝仍保持最终失败。

## 安装

**Docker Hub：**

```bash
docker pull yideng966/lightagent:v2.1.16
```

**GitHub Container Registry：**

```bash
docker pull ghcr.io/yideng966/lightagent:v2.1.16
```

**完整技能镜像：**

```bash
docker pull yideng966/lightagent:v2.1.16-skills-full
```
