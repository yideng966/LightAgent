> LightAgent - 多渠道 Agent Harness 与可长期运行的 AI 助手框架

本版本回退了上一版本中的一项微信群图片理解调整，恢复此前稳定的图片消息处理方式，避免新判定规则带来的兼容性问题；其他已发布功能保持不变。

## Bug 修复

- 回退微信群图片理解失败判定和自由回复静默条件的调整，恢复 `v2.2.9` 之前的图片消息处理行为。
- 保留一键安装时对微信群运行环境和依赖的自动检查，不受本次回退影响。

---

## 安装

**Docker Hub：**

```bash
docker pull yideng966/lightagent:v2.2.10
```

**GitHub Container Registry：**

```bash
docker pull ghcr.io/yideng966/lightagent:v2.2.10
```

**完整技能镜像：**

```bash
docker pull yideng966/lightagent:v2.2.10-skills-full
docker pull ghcr.io/yideng966/lightagent:v2.2.10-skills-full
```
