> LightAgent - 多渠道 Agent Harness 与可长期运行的 AI 助手框架

本版本调整新部署的默认回复风格，移除 Agent 与微信群内置人设中主动使用 emoji 或微信文字表情的引导，减少普通回复反复附带 `[破涕为笑]`、`[吃瓜]` 等文字表情的情况。独立媒体表情包能力保持原有行为。

## 优化改进

- 新建工作区的中英文 `AGENT.md`、首次初始化提示和 Agent 通用提示不再要求使用 emoji；用户仍可通过已有工作区或自定义人设按需配置回复风格。
- 微信群内置人设不再提供微信文字表情示例，同时继续保留表情包自动收集、主动回复频率、检索和发送能力，不改变既有表情包配置。

---

## 安装

**Docker Hub：**

```bash
docker pull yideng966/lightagent:v2.2.8
```

**GitHub Container Registry：**

```bash
docker pull ghcr.io/yideng966/lightagent:v2.2.8
```

**完整技能镜像：**

```bash
docker pull yideng966/lightagent:v2.2.8-skills-full
docker pull ghcr.io/yideng966/lightagent:v2.2.8-skills-full
```
