> LightAgent - 多渠道 Agent Harness 与可长期运行的 AI 助手框架

本版本集中提升个人微信群渠道的日常运营与长期记忆体验：进退群通知默认可用，扫码入群欢迎识别更加稳定；群永久记忆现在统一归入记忆管理，并能在重启、历史积压和模型临时故障后持续、可诊断地生成。

## 优化改进

- 群永久记忆统一迁入 Web 控制台「管理 -> 记忆 -> 群记忆」，原「管理 -> 知识 -> 群知识」和「群聊 -> 永久记忆」入口已移除。管理员现在可以在一个页面查询、新增和停用当前稳定群记忆，查看积压、游标、失败与历史生成状态，并测试带最低分阈值的严格召回；群友画像和完整注入预览分别保留在「群聊 -> 群友画像」与「群聊 -> 拟人化」。
- 群记忆自动生成改为根据已选择的稳定群、归档高水位和持久化游标恢复任务；稀疏历史窗口可按总积压或最长等待继续推进，历史生成使用独立断点且不会回退增量游标。临时模型故障会持久化退避，非法结构化结果最多受控修复一次，无关显式查询不再回退最新记忆。
- 入群欢迎与离群通知的全局开关默认开启；Web 控制台仍可分别关闭并保存，显式 `false`、按群禁用、稳定群选择和身份确认门禁保持优先生效。

## Bug 修复

- 修复 wechat4u 无法识别无前导空格的扫码入群系统文案，导致新成员未收到欢迎的问题。可信系统消息现在会进入既有成员事件与安全降级流程，普通成员发送相同文本或跨群载荷不会误触发欢迎。

## 破坏性变更

- 受影响范围为 `config.json` 中缺少 `wechat_group_join_welcome_enabled` 或 `wechat_group_leave_notice_enabled` 的微信群部署。旧版本缺少字段时按关闭处理，本版本改为按开启处理；如需保持原关闭行为，请在 Web 控制台「群聊 -> 进退群消息」关闭对应开关并保存，或在配置中显式设置为 `false`。已有显式关闭和按群禁用配置不受影响。

## 安装

**Docker Hub：**

```bash
docker pull yideng966/lightagent:v2.1.17
```

**GitHub Container Registry：**

```bash
docker pull ghcr.io/yideng966/lightagent:v2.1.17
```

**完整技能镜像：**

```bash
docker pull yideng966/lightagent:v2.1.17-skills-full
```
