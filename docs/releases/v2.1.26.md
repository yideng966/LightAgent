> LightAgent - 多渠道 Agent Harness 与可长期运行的 AI 助手框架

本版本重新梳理个人微信群的模型回复边界。正常正文不再因为尾部协议标签被错误切换到备用模型，工具查询的中间进度、思考内容和内部静默说明也不会作为群消息发送。

## 优化改进

- 微信群恢复接受模型的普通纯文本最终答复，不再要求特定 XML 包装；自定义 OpenAI 兼容端点会按照全局思考开关传递启用或禁用状态，同时继续隔离思考内容与最终正文。

## Bug 修复

- 修复正常答复尾部带有 `s`、`analysis` 结束标签或空工具标签等 Provider 残片时错误切换备用模型的问题；现在会在当前候选内清除残片并保留有效正文。
- 修复工具查询后将“让我继续看看”等中间进度误当成最终结果的问题；只有完整、自包含的最终答复才会进入微信群发送与会话历史。
- 兼容提取嵌套 `send/message`、`send` 的 `message` 属性和 JSON `send.message` 中的最终正文，Provider 临时路径及其他内部字段不会被访问或发送。
- 修复“无需接话”“保持安静”等整条括号控制说明被发送到群里的问题，同时避免误拦截普通正文中的括号内容。

## 安装

**Docker Hub：**

```bash
docker pull yideng966/lightagent:v2.1.26
```

**GitHub Container Registry：**

```bash
docker pull ghcr.io/yideng966/lightagent:v2.1.26
```

**完整技能镜像：**

```bash
docker pull yideng966/lightagent:v2.1.26-skills-full
docker pull ghcr.io/yideng966/lightagent:v2.1.26-skills-full
```
