> LightAgent - 多渠道 Agent Harness 与可长期运行的 AI 助手框架

本版本增强 Web 控制台模型管理体验，可以直接获取厂商模型目录、检索并选择模型，同时减少同一厂商在不同能力之间的重复请求。

## 新增功能

- 主模型、LLM Scorer、图像理解、图像生成、语音识别、语音合成和向量模型支持从已配置厂商获取模型目录，并通过可编辑下拉框进行中文或英文模糊检索；厂商接口不可用时仍可手工填写模型 ID。
- 主模型的备用模型支持独立选择厂商、获取模型目录、检索和选择模型，原有优先级调整与故障切换配置保持不变。

## 优化改进

- 同一页面会话内，成功获取的模型目录会按厂商复用于其他能力和备用模型；再次点击获取按钮仍可主动刷新，修改厂商凭据或 API Base 后会清除旧缓存。
- 模型目录请求按 OpenAI-compatible、Anthropic 和 Gemini 协议归一化，并限制重定向、超时、响应大小和分页范围，错误信息不会回显厂商凭据或第三方响应正文。

## 安装

**Docker Hub：**

```bash
docker pull yideng966/lightagent:v2.2.3
```

**GitHub Container Registry：**

```bash
docker pull ghcr.io/yideng966/lightagent:v2.2.3
```

**完整技能镜像：**

```bash
docker pull yideng966/lightagent:v2.2.3-skills-full
docker pull ghcr.io/yideng966/lightagent:v2.2.3-skills-full
```
