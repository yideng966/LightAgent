> LightAgent - 多渠道 Agent Harness 与可长期运行的 AI 助手框架

本版本修复个人微信群中定向自由回复被错误判定为过期的问题。多人连续发言时，已经生成且明确面向机器人的回复会继续按群内顺序确认发送，不再因后续普通群消息而被静默丢弃。

## Bug 修复

- 修复 `new_thread`、`resume_thread` 等面向机器人的自由回复在生成期间收到新群消息后，被统一套用 ambient stale 规则并取消发送的问题。
- 真正的 `observe_only` 环境接话仍保留发送前 room revision 复核，避免话题已经推进后出现迟到插话；sidecar 发送确认和失败回滚边界保持不变。

## 安装

**Docker Hub：**

```bash
docker pull yideng966/lightagent:v2.1.24
```

**GitHub Container Registry：**

```bash
docker pull ghcr.io/yideng966/lightagent:v2.1.24
```

**完整技能镜像：**

```bash
docker pull yideng966/lightagent:v2.1.24-skills-full
docker pull ghcr.io/yideng966/lightagent:v2.1.24-skills-full
```
