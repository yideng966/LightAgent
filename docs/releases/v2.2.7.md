> LightAgent - 多渠道 Agent Harness 与可长期运行的 AI 助手框架

本版本统一了 Agent 深度思考的启停和强度配置。用户可以在 Web 控制台选择低、中、高、极高四档强度，LightAgent 会按当前模型 Provider 的实际协议转换请求，避免向不兼容渠道发送通用参数。

## 新增功能

- Web 控制台“配置 -> Agent 配置”新增低、中、高、极高四档思考强度；关闭深度思考时保留所选档位，重新开启后继续使用。
- Custom Provider 支持显式选择思考协议，可按 `thinking` 对象、DeepSeek、`enable_thinking` 或 OpenAI `reasoning_effort` 协议适配自定义上游；旧配置默认不发送未知思考参数。

## 优化改进

- OpenAI、Claude、Gemini、DeepSeek、DashScope、ModelScope 等文本模型请求按各自能力转换统一思考配置；Provider 不支持强度时只应用开关，档位较少时按相对等级合并。
- 内部无状态评分请求使用请求级关闭标记，旧 `reasoning_effort=none` 会在路由层消费，不再无条件透传给上游渠道。

## 安装

**Docker Hub：**

```bash
docker pull yideng966/lightagent:v2.2.7
```

**GitHub Container Registry：**

```bash
docker pull ghcr.io/yideng966/lightagent:v2.2.7
```

**完整技能镜像：**

```bash
docker pull yideng966/lightagent:v2.2.7-skills-full
docker pull ghcr.io/yideng966/lightagent:v2.2.7-skills-full
```
