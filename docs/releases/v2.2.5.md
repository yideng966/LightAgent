> LightAgent - 多渠道 Agent Harness 与可长期运行的 AI 助手框架

本版本补全个人微信群定时任务的目标群编辑能力。管理员现在可以在 Web 控制台查看任务当前投递群，并从已选择的稳定群中切换目标，无需删除后重新创建任务。

## 优化改进

- 编辑个人微信群定时任务时新增目标群下拉，当前目标会被明确标识；目标暂时离线或已不在通道已选列表时仍保留显示，避免编辑时意外清空。
- 切换目标后会同步更新稳定群、运行时群快照、群名和会话作用域，并保留任务创建者身份；投递前继续通过稳定身份解析当前运行时群。

## 安全修复

- Scheduler 更新接口只允许将任务切换到个人微信群设置中已选择的稳定群，并在切换后清除旧目标遗留的身份绑定失败状态，其他通道行为保持不变。

## 安装

**Docker Hub：**

```bash
docker pull yideng966/lightagent:v2.2.5
```

**GitHub Container Registry：**

```bash
docker pull ghcr.io/yideng966/lightagent:v2.2.5
```

**完整技能镜像：**

```bash
docker pull yideng966/lightagent:v2.2.5-skills-full
docker pull ghcr.io/yideng966/lightagent:v2.2.5-skills-full
```
