> LightAgent - 多渠道 Agent Harness 与可长期运行的 AI 助手框架

本版本继续收紧微信群的思考过程隔离。即使模型或兼容代理把内部分析直接混入普通正文且不提供任何标记，群成员也只会收到净化后的最终答复。

## Bug 修复

- 修复部分模型在流式正文中输出无标签内部分析时，分析前言可能被发送到微信群并写入会话历史的问题；微信群现在会等完整正文净化后再发送，并保留正常多段答复。
- 修复复用 Agent 时残留的 Web 渠道状态可能影响微信群思考过滤的问题；过滤现在以当前消息的实际渠道为准。

## 安装

**Docker Hub：**

```bash
docker pull yideng966/lightagent:v2.1.20
```

**GitHub Container Registry：**

```bash
docker pull ghcr.io/yideng966/lightagent:v2.1.20
```

**完整技能镜像：**

```bash
docker pull yideng966/lightagent:v2.1.20-skills-full
```
