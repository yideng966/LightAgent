> LightAgent - 多渠道 Agent Harness 与可长期运行的 AI 助手框架

本版本修复 Docker 多架构镜像发布阶段的清理竞态。基础版与完整技能版现在会先完成全部清单发布，再清理 GHCR 未标记版本，避免完整技能镜像偶发发布失败。

## Bug 修复

- 修复基础版与完整技能版并行发布时，基础版可能提前删除 GHCR canonical digest 或 attestation 子 manifest，导致 `skills-full` 多架构清单因内容不存在而失败的问题；清理现在只会在两个变体全部发布成功后执行，任一变体失败时自动跳过。

---

## 安装

**Docker Hub：**

```bash
docker pull yideng966/lightagent:v2.1.21
```

**GitHub Container Registry：**

```bash
docker pull ghcr.io/yideng966/lightagent:v2.1.21
```

**完整技能镜像：**

```bash
docker pull yideng966/lightagent:v2.1.21-skills-full
docker pull ghcr.io/yideng966/lightagent:v2.1.21-skills-full
```
