> LightAgent - 多渠道 Agent Harness 与可长期运行的 AI 助手框架

本版本完整承接 v2.1.7 的微信群记忆与知识隔离能力，并修复该版本 Windows 桌面端和 `skills-full` 镜像的发布打包失败。安装和升级请使用 v2.1.8，以获得完整的平台产物。

## 新增功能

- 群永久记忆升级为按稳定群 ID 隔离的两阶段梦境蒸馏：先摘要当前群的安全归档，再结合当前群已有记忆生成或更新长期记忆；支持空闲自动触发、Web 手动运行、历史归档生成和运行诊断。
- Web 控制台“知识”页新增“全局知识 / 群知识”切换，可按已配置的稳定群搜索、新增和停用群知识；原有全局 Markdown 文档、导入和知识图谱功能保持不变。
- 新增默认仅预览的全局记忆历史重置脚本，可清理全局日记、梦境蒸馏和自主进化历史，同时保留群归档、群知识、用户作用域记忆、普通会话及个人知识库。

## 优化改进

- 全局摘要、全局梦境蒸馏和群记忆蒸馏统一复用文本模型主备顺序与熔断状态；临时模型故障后任务可以重试，失败不会提前推进处理游标。
- 群知识查询统一绑定当前稳定群作用域，群聊上下文和 Agent 工具不再接受模型自行指定群 ID；普通群成员保持只读，写入和停用仍需当前群管理员权限。
- Docker 多架构构建为系统包下载增加有限重试，降低临时网络连接重置导致完整技能镜像缺失的概率，同时继续对真实依赖错误快速失败。

## Bug 修复

- 修复微信群消息可能因上下文压缩、每日汇总或记忆管理回落而写入全局记忆，并进一步参与全局自主进化的问题；稳定群身份缺失时现在会拒绝写入，不会降级到共享作用域。
- 修复群永久记忆、证据和知识检索可能跨稳定群混入的问题；服务端现在对群作用域、证据归属、敏感内容和写入操作进行强校验。
- 修复 Windows 发布 Runner 因非 UTF-8 输出编码无法打印版本同步状态，导致桌面安装包尚未开始构建便失败的问题。
- 修复 `skills-full` ARM64 镜像在单个 Debian 软件包下载连接被重置时直接终止整个多架构发布的问题。

## 安装

**Docker Hub：**

```bash
docker pull yideng966/lightagent:v2.1.8
```

**GitHub Container Registry：**

```bash
docker pull ghcr.io/yideng966/lightagent:v2.1.8
```

**完整技能镜像：**

```bash
docker pull yideng966/lightagent:v2.1.8-skills-full
```

**桌面端：**

从本 Release 的 Assets 下载适用于当前平台的 `.exe` 或 `.dmg` 安装包。
