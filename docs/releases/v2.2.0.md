> LightAgent - 多渠道 Agent Harness 与可长期运行的 AI 助手框架

本版本将代码恢复到 2.1.18 的稳定基线，同时保留贡献指南中文化和 Docker 多架构清单发布竞态修复。除这两项明确保留的变更外，2.1.18 之后引入的代码与行为不再包含在本版本中。

## 优化改进

- 贡献指南恢复为简体中文，并明确 Issue、Pull Request、代码注释和提交说明的语言规范，便于中文社区协作。

## Bug 修复

- 保留 Docker 多架构镜像发布清理竞态修复；GHCR 未标记版本只会在基础版与完整技能版清单全部发布成功后清理，任一变体失败时跳过清理。

## 破坏性变更

- 代码基线由 2.1.30 回退到 2.1.18，并仅保留上述两项变更。依赖 2.1.19 至 2.1.30 期间其他新增功能、修复、配置项或微信群行为的用户会受到影响；升级后这些能力将恢复为 2.1.18 的实现或不再存在。升级前请备份配置与运行数据，在测试环境核对现有配置、Agent 流式回复和微信群链路；仍依赖被回退能力的部署不应直接升级到本版本。

## 安装

**Docker Hub：**

```bash
docker pull yideng966/lightagent:v2.2.0
```

**GitHub Container Registry：**

```bash
docker pull ghcr.io/yideng966/lightagent:v2.2.0
```

**完整技能镜像：**

```bash
docker pull yideng966/lightagent:v2.2.0-skills-full
docker pull ghcr.io/yideng966/lightagent:v2.2.0-skills-full
```
