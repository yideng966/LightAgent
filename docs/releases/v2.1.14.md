> LightAgent - 多渠道 Agent Harness 与可长期运行的 AI 助手框架

本版本优化 Docker 镜像的稳定分层与构建上下文。已拉取过当前镜像的用户在后续普通源码更新时，可以继续复用系统、Python、Chromium、Node.js 和微信群侧车依赖层，同时保持完整的开箱即用能力与原生双架构构建。

## 优化改进

- 调整最终镜像层顺序，将 Node.js、npm 与微信群侧车生产依赖放到应用源码之前，避免普通源码和版本号变化使稳定重层失去直接缓存命中。
- 缩小 Docker 构建上下文，不再把测试、文档、开发计划、历史桌面端、运行日志和服务器访问信息复制到运行镜像。
- 继续使用原生 AMD64、ARM64 Runner 和按镜像变体、架构隔离的跨版本 Registry Cache，缩短重复发布构建时间且不移除 Chromium 等默认能力。

---

## 安装

**Docker Hub：**

```bash
docker pull yideng966/lightagent:v2.1.14
```

**GitHub Container Registry：**

```bash
docker pull ghcr.io/yideng966/lightagent:v2.1.14
```

**完整技能镜像：**

```bash
docker pull yideng966/lightagent:v2.1.14-skills-full
```
