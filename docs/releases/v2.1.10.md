> LightAgent - 多渠道 Agent Harness 与可长期运行的 AI 助手框架

本版本将发布链路收敛到持续维护的 Python、Web、CLI 和 Docker 能力，避免已停止维护的桌面安装包阻塞版本发布。`app.py` 及其后端运行方式保持不变。

## 优化改进

- 推送版本标签后，GitHub Release 仅校验并发布对应版本说明；Docker Hub 与 GHCR 镜像继续由独立工作流构建和发布，不再等待桌面平台打包。

## 破坏性变更

- Electron 桌面端停止维护，不再提供新的 Windows `.exe` 或 macOS `.dmg` 安装包。此前依赖桌面安装包的用户请改用 `python app.py`、`lightagent` CLI 或 Docker 启动，并通过 Web 控制台进行图形化管理；Web、CLI、Docker 和各消息渠道不受影响。

---

## 安装

**Docker Hub：**

```bash
docker pull yideng966/lightagent:v2.1.10
```

**GitHub Container Registry：**

```bash
docker pull ghcr.io/yideng966/lightagent:v2.1.10
```

**完整技能镜像：**

```bash
docker pull yideng966/lightagent:v2.1.10-skills-full
```
