> LightAgent - 多渠道 Agent Harness 与可长期运行的 AI 助手框架

本版本修复 Android 移动端 Web 控制台侧边栏入口不可见的问题，并收敛微信群管理员门禁交互，避免页面异常跳顶和权限提示误发到群内。

## Bug 修复

- Web 控制台在 Android 浏览器动态地址栏改变可视区域时，会保持顶部导航和侧边栏入口可见；登录初始化不再自动唤起移动端软键盘，菜单按钮触控区与展开状态也同步改善。
- 微信群管理员门禁详情展开或收起后会保留当前滚动位置；普通成员触发管理员专属能力时仍由通道层硬拒绝，但不再向群内发送权限提示，其他业务错误继续正常反馈。

## 安装

**Docker Hub：**

```bash
docker pull yideng966/lightagent:v2.2.2
```

**GitHub Container Registry：**

```bash
docker pull ghcr.io/yideng966/lightagent:v2.2.2
```

**完整技能镜像：**

```bash
docker pull yideng966/lightagent:v2.2.2-skills-full
docker pull ghcr.io/yideng966/lightagent:v2.2.2-skills-full
```
