> LightAgent - 多渠道 Agent Harness 与可长期运行的 AI 助手框架

本版本修复 Docker `latest` 镜像版本号可能回退的问题，并完善个人微信群的语音忽略和直接艾特上下文体验。升级后 Web、CLI 与 Python 包版本保持一致。

## 优化改进

- 个人微信群新增“忽略语音”模式；启用后群语音仍会下载并归档，但不会转写、调用模型或发送回复。
- 群成员直接艾特机器人时会按现有开关使用最近群聊上下文，更准确地承接群内正在讨论的话题。

## Bug 修复

- Docker 正式镜像改为仅由 `v*` 标签发布，避免手动构建读取旧版本号并覆盖 `latest`；版本标签、Web 左下角、CLI 与 Python 包元数据现在保持一致。

---

## 安装

**Docker Hub：**

```bash
docker pull yideng966/lightagent:v2.1.11
```

**GitHub Container Registry：**

```bash
docker pull ghcr.io/yideng966/lightagent:v2.1.11
```

**完整技能镜像：**

```bash
docker pull yideng966/lightagent:v2.1.11-skills-full
```
