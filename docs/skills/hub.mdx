[LightAgent Skill Hub](https://xiaoguiwucan.github.io/LightAgent-SkillHub/) is LightAgent's official GitHub-based registry. Its [source repository](https://github.com/xiaoguiwucan/LightAgent-SkillHub) contains skill sources, contribution rules, CI validation, deterministic packages, and the signed static index. `skills.cowagent.ai` remains available as a separately labelled, browse-only original marketplace. LightAgent only links to its publisher pages and does not install or update those entries.

## Browse and install

In the Web console, open **Skills -> Get online skills**. The dialog separates both sources and provides search, translated categories, and 12-item pagination. Official Hub entries support details, installation, updates, uninstall, and cross-page batch management. Original marketplace entries only provide an external **View skill page** action because their packages and dependencies do not implement the signed one-click installation contract.

```text
/skill list --remote
/skill search <keyword>
/skill install <name>
```

After Install, LightAgent verifies the artifact and prepares declared Python, npm, and SHA-256-pinned download dependencies in a private skill environment. The UI distinguishes **official signature**, **reviewed hash**, and **first-install lock** integrity states.

## Updates and rollback

Background jobs only check at startup and every six hours; they never update a skill automatically. Before an explicit update, the Web console shows current and target versions, source, release notes, breaking changes, and dependency, capability, and permission changes.

```bash
lightagent skill outdated
lightagent skill update <name>
lightagent skill rollback <name>
lightagent skill verify [name]
```

The previous package, dependency environment, and lock record are preserved. A package, dependency, entrypoint, or integrity verification failure restores them automatically.

## System capabilities

Skills declare stable `requirements.capabilities` names: `office-documents`, `media-processing`, or `browser-automation`. LightAgent never executes sudo, apt, or brew during skill installation. Use `yideng966/lightagent:skills-full`, or build a custom image with `SKILL_CAPABILITY_PACKS=office,media,browser`.

## Complete uninstall and encrypted backup

A Web uninstall permanently removes package code, private dependencies, rollback versions, configuration, secrets, user data, and lock records. The dialog can first export a single-skill `.laskill-backup`, encrypted with a scrypt-derived key and AES-256-GCM. Reinstall the same skill before restoring its backup.

## Skill Runner boundary

Schema v2 script skills declare structured `lightagent.entrypoints` and run through `skill_run` without shell command strings. Runner constrains the request snapshot, environment, paths, time, output, memory, and process count, and records an argument-free audit event. This is controlled process isolation, not a complete filesystem or network sandbox. Older skills remain in **Runner compatibility isolation** while they are migrated.

## Contributing

Fork [LightAgent-SkillHub](https://github.com/xiaoguiwucan/LightAgent-SkillHub), copy `templates/skill/` to `skills/<name>/`, declare Schema v2 metadata and tests, run the validation and registry build scripts, and submit a Chinese Pull Request describing behavior, tests, dependencies, permissions, compatibility, and changes.
