[LightAgent Skill Hub](https://xiaoguiwucan.github.io/LightAgent-SkillHub/) is the official GitHub-based registry for LightAgent. Its [source repository](https://github.com/xiaoguiwucan/LightAgent-SkillHub) contains every published skill, contribution rules, validation workflows, deterministic packages, checksums, and the static catalog.

LightAgent verifies the registry signature and package SHA-256 before installation. If GitHub is temporarily unavailable, it uses only the last locally cached registry whose signature remains valid. The legacy `skills.cowagent.ai` service remains a compatibility fallback.

## Browse and install

Use the Web console's Skills view, chat commands, or the terminal:

In the Web console, open **Skills** and choose **Get online skills**. The online library opens as a separate dialog with search, category filters, pagination, skill details, and install/update actions. The main Skills page remains focused on installed skills and built-in tools even when the Hub grows.

```text
/skill list --remote
/skill search <keyword>
/skill install <name>
```

```bash
lightagent skill list --remote
lightagent skill search <keyword>
lightagent skill install <name>
```

Declared dependencies are installed automatically after the user chooses Install. Chat-based installation, update, rollback, and uninstall remain restricted to configured owners or administrators.

## Updates and rollback

Updates are never applied silently:

```bash
lightagent skill outdated
lightagent skill update <name>
lightagent skill rollback <name>
lightagent skill verify [name]
```

Installed versions and artifact identities are stored in `<workspace>/skills.lock.json`. Package code, dependency environments, configuration, and user-generated data are stored separately. A normal uninstall preserves configuration and user data.

## Security boundary

The registry declares network domains, file paths, tools, dependencies, and Docker notes. These fields support automated and maintainer review; they are not a per-skill runtime sandbox. Review third-party skills before use.

## Contributing

Fork [xiaoguiwucan/LightAgent-SkillHub](https://github.com/xiaoguiwucan/LightAgent-SkillHub), copy the skill template, run the validation scripts, and submit a Chinese Pull Request. Community skills cannot silently replace LightAgent's built-in skills or reserved namespaces.
