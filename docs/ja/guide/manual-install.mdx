## ソースコードによるデプロイ

### 1. プロジェクトをクローン

```bash
git clone https://github.com/yideng966/LightAgent
cd LightAgent/
```

<Tip>
  ネットワークに問題がある場合は、ミラーを使用してください: https://github.com/yideng966/LightAgent
</Tip>

### 2. 依存パッケージをインストール

コア依存パッケージ（必須）：

```bash
pip3 install -r requirements.txt
```

オプション依存パッケージ（推奨）：

```bash
pip3 install -r requirements-optional.txt
```

ソースコードによるデプロイで個人 WeChat グループに接続する場合は、Node.js と sidecar の依存パッケージもインストールします：

```bash
cd channel/wechat_group/sidecar
npm install
cd ../../..
```

### 3. LightAgent CLI をインストール

サービスとスキルを管理するためのコマンドラインツールをインストールします：

```bash
pip3 install -e .
```

インストール後、`lightagent` コマンドが使用可能になります：

```bash
lightagent help
```

<Note>
  このステップは推奨です。インストール後、`lightagent start`、`lightagent stop`、`lightagent update` でサービスを管理でき、`lightagent skill` でスキルを管理できます。CLI をインストールしない場合は、`./run.sh` または `python3 app.py` で実行できます。
</Note>

### 4. 設定

設定テンプレートをコピーして編集します：

```bash
cp config-template.json config.json
```

`config.json` にモデルの API キー、チャネルタイプ、その他の設定を入力します。詳細は[モデルのドキュメント](/ja/models/index)を参照してください。

### 5. 実行

**LightAgent CLI を使用して実行（推奨）：**

```bash
lightagent start
```

**またはローカルでフォアグラウンド実行：**

```bash
python3 app.py
```

デフォルトでは Web コンソールが起動します。`http://localhost:9899` にアクセスしてチャットできます。

**サーバーでバックグラウンド実行（CLI 未使用時）：**

```bash
nohup python3 app.py & tail -f nohup.out
```

<Tip>
  サーバーにデプロイする場合は、ファイアウォールまたはセキュリティグループでポート `9899` を開放して Web コンソールにアクセスできるようにしてください。セキュリティのため、特定の IP のみにアクセスを制限することを推奨します。
</Tip>

## Docker によるデプロイ

Docker デプロイでは、ソースコードのクローンや Python、Node.js、npm 依存パッケージのインストールは不要です。イメージには `/usr/local/bin/node`、個人 WeChat グループ用 Wechaty sidecar、およびロック済みの本番依存パッケージが含まれています。Agent モードからホストへより広範にアクセスする必要がある場合のみ、ソースコードによるデプロイを選択してください。

<Note>
  [Docker](https://docs.docker.com/engine/install/) と docker-compose が必要です。
</Note>

**1. Compose をダウンロード**

```bash
curl -O https://raw.githubusercontent.com/yideng966/LightAgent/master/docker/docker-compose.yml
```

`.env` を作成せず、そのまま起動できます。`WEB_PASSWORD` が未設定の場合、entrypoint が強力なランダムパスワードを生成し、`./config/config.json` に永続化します。固定パスワードを指定する場合は、`docker/.env.example` を Compose と同じディレクトリの `.env` にコピーして編集し、実際の値を Git にコミットしないでください。

**2. コンテナを起動**

```bash
sudo docker compose up -d
sudo docker compose logs lightagent
```

ログに自動管理された Web コンソールのパスワードが表示されます。`http://localhost:9899` を開いてログインし、モデルを設定します。その後「チャネル管理 -> チャネルを追加 -> 個人 WeChat グループ」から QR コードをスキャンします。Docker ホストで sidecar の `npm install` を実行する必要はありません。

**3. ログを確認**

```bash
sudo docker logs -f lightagent
```

Compose は `docker-compose.yml` からの相対パスで、次の 2 つの永続化ディレクトリを使用します：

- `./config` は `/home/agent/.lightagent` にマウントされ、`config.json`、シークレット、ログ、プラグイン設定とユーザーがインストールしたプラグイン、WeChat ログイン状態、メディア、グループデータベースを保存します。名前にかかわらず設定ファイルだけのディレクトリではないため、ディレクトリ全体をバックアップしてください。
- `./data` は `/home/agent/lightagent` にマウントされ、Agent workspace、メモリ、ナレッジベース、スキル、MCP 設定、scheduler データを保存します。生成画像は `./data/images`（コンテナ内では `/home/agent/lightagent/images`）に永続化されます。
- `/app` はイメージに属し、アプリケーションコード、Playwright、sidecar の `node_modules` を含みます。ここに volume をマウントしないでください。

Compose は Web サービスを `0.0.0.0` にバインドし、パスワードが指定されていない場合は自動生成します。公開する場合は、ファイアウォールまたはセキュリティグループでポート `9899` の接続元を制限してください。コンテナを再起動または再作成しても `./config` と `./data` は上書きされません。

## 主要な設定項目

```json
{
  "channel_type": "web",
  "model": "deepseek-v4-flash",
  "deepseek_api_key": "",
  "agent": true,
  "agent_workspace": "~/lightagent",
  "agent_max_context_tokens": 40000,
  "agent_max_context_turns": 30,
  "agent_max_steps": 15,
  "lightagent_lang": "auto"
}
```

| パラメータ | 説明 | デフォルト値 |
| --- | --- | --- |
| `channel_type` | チャネルタイプ | `web` |
| `model` | モデル名 | `deepseek-v4-flash` |
| `agent` | Agent モードを有効化 | `true` |
| `agent_workspace` | Agent のワークスペースパス | `~/lightagent` |
| `agent_max_context_tokens` | 最大コンテキストトークン数 | `40000` |
| `agent_max_context_turns` | 最大コンテキストターン数 | `30` |
| `agent_max_steps` | タスクごとの最大判断ステップ数 | `15` |
| `lightagent_lang` | UI・コマンド文言・システムプロンプトなどの言語。`auto` で自動検出、`zh` / `en` も指定可 | `auto` |

<Tip>
  すべての設定オプションはプロジェクトの [`config.py`](https://github.com/yideng966/LightAgent/blob/master/config.py) に記載されています。Docker では Web コンソールからモデルとチャネルを設定し、変更内容は `./config/config.json` に永続化されます。保存済みの値を上書きするため、空の API キーやモデル環境変数を Compose に追加しないでください。
</Tip>
